Per un sito statico bastano pochi header, ma conviene metterli tutti.

**1. Strict-Transport-Security**
```
Strict-Transport-Security: max-age=31536000; includeSubDomains
```
Obbliga il browser a usare sempre HTTPS. Il `max-age` deve essere di almeno 31536000 secondi (un anno). Con `includeSubDomains` la regola vale anche per i sottodomini.

**2. Content-Security-Policy**
```
Content-Security-Policy: default-src 'self'; frame-ancestors 'none'
```
È l'header più importante, perché blocca l'iniezione di script di terze parti. Con `default-src 'self'` il browser carica risorse solo dal tuo dominio. Aggiungendo `frame-ancestors 'none'` la stessa policy protegge anche dal clickjacking (vedi il punto 5).

**3. X-Content-Type-Options**
```
X-Content-Type-Options: nosniff
```
Impedisce al browser di indovinare il tipo di contenuto di un file. Il browser usa solo il tipo che dichiari tu.

**4. Referrer-Policy**
```
Referrer-Policy: strict-origin-when-cross-origin
```
Quando un visitatore passa dal tuo sito a un altro sito, il percorso completo della pagina non viene inviato.

**5. Protezione dal clickjacking**
Hai due modi:
- `X-Frame-Options: DENY`
- oppure `frame-ancestors 'none'` dentro la Content-Security-Policy, come nell'esempio del punto 2.

Basta uno dei due, ma puoi anche metterli entrambi.

**6. Permissions-Policy**
```
Permissions-Policy: camera=(), microphone=(), geolocation=()
```
Spegne camera, microfono e geolocalizzazione. Un sito statico di solito non li usa, quindi conviene disattivarli.

**Da non mettere: X-XSS-Protection**
Questo header è deprecato e va omesso. I browser moderni lo ignorano, e nelle versioni vecchie poteva introdurre vulnerabilità invece di proteggere. Se compare in una vecchia configurazione, toglilo.

Puoi impostare tutti questi header nella configurazione del server web o del servizio di hosting che usi.
