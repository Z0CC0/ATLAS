Basta una chiusura che tiene il timer e lo azzera a ogni chiamata:

```js
function debounce(fn, ms) { let t; return (...args) => { clearTimeout(t); t = setTimeout(() => fn(...args), ms); }; }
```

Ci sono tre dettagli da non sbagliare:

- **`clearTimeout(t)` prima di ogni nuovo `setTimeout`.** Senza, i timer si accumulano e la funzione parte più volte.
- **`let t` nella chiusura, non dentro la funzione restituita.** Altrimenti ogni chiamata ha il proprio timer e il debounce non avviene.
- **`...args` con lo spread.** Senza, la funzione chiamata riceve argomenti vuoti.

Questa versione non restituisce niente. Se ti serve il valore di ritorno di `fn`, devi usare una Promise.

Se vuoi il comportamento opposto, cioè eseguire subito e poi ignorare le chiamate per un periodo, ti serve un throttle. È un'altra funzione.
