`let` e `const` hanno ambito di blocco, a differenza di `var`.

`let` permette la riassegnazione:
```js
let x = 1;
x = 2; // ok
```

`const` impedisce di riassegnare il nome, ma non impedisce di modificare il valore:
```js
const y = 1;
y = 2; // TypeError
```

Un oggetto dichiarato con `const` può cambiare al suo interno:
```js
const obj = { a: 1 };
obj.a = 2;   // ok
obj = {};    // TypeError
```
