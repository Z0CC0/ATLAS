Differenza principale: **riassegnazione**.

- `let`: nome riassegnabile.
- `const`: nome non riassegnabile. Valore però resta modificabile. `const` blocca solo il legame tra nome e valore.

Esempio con oggetto `const`, che può cambiare al suo interno:

```js
const utente = { nome: "Anna" };
utente.nome = "Luca";      // OK: modifica interna
utente = { nome: "Sara" }; // TypeError: riassegnazione vietata

let contatore = 0;
contatore = 1;             // OK: let permette riassegnazione
```

In comune: `let` e `const` hanno ambito di blocco. `var` invece non ha ambito di blocco.
