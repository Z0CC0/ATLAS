```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Uso:

```js
const onResize = debounce(() => console.log('resize finito'), 200);
window.addEventListener('resize', onResize);
```

Punti da non sbagliare:

- **Chiama `clearTimeout(t)` prima di ogni nuovo `setTimeout`.** Senza questa chiamata i timer si accumulano e `fn` parte più volte.
- **Dichiara `t` nella chiusura, fuori dalla funzione restituita.** Se `t` sta dentro la funzione restituita, ogni chiamata ha un timer suo e il debounce non avviene.
- **Inoltra gli argomenti con lo spread (`...args`).** Senza lo spread, `fn` riceve gli argomenti vuoti.
- **Questa versione non restituisce niente.** Se ti serve il valore di ritorno di `fn`, devi usare una Promise.
- **Per il caso opposto usa un throttle.** Il throttle esegue subito e poi ignora le chiamate per un periodo. È una funzione diversa dal debounce.
