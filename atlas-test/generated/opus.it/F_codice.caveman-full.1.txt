Ecco versione minima:

```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Uso:

```js
const onResize = debounce(() => console.log('resize'), 200);
window.addEventListener('resize', onResize);
```

Tre punti dove è facile sbagliare:

- **`clearTimeout` prima di ogni nuovo `setTimeout`.** Senza questa chiamata i timer si accumulano e la funzione parte più volte.
- **`t` nella chiusura, non dentro la funzione restituita.** Se `t` sta dentro, ogni chiamata ha il proprio timer e il debounce non avviene.
- **Argomenti inoltrati con lo spread (`...args`).** Senza spread la funzione chiamata riceve argomenti vuoti.

Limiti:

- Questa versione non restituisce niente. Se ti serve il valore di ritorno, devi usare una Promise.
- Se vuoi il caso opposto, cioè eseguire subito e poi ignorare le chiamate per un periodo, ti serve un throttle. Il throttle è un'altra funzione.
