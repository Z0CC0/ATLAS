Nessuna libreria necessaria:

```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Chiama `clearTimeout` prima di ogni nuovo `setTimeout`, altrimenti i timer si accumulano e la funzione parte più volte.

Tieni `t` nella chiusura, non dentro la funzione restituita: ogni chiamata avrebbe il proprio timer e il debounce non avverrebbe.

Inoltra gli argomenti con lo spread, altrimenti la funzione li riceve vuoti.

Questa versione non restituisce niente. Se ti serve il valore di ritorno, usa una Promise.

Per il caso opposto, cioè eseguire subito e poi ignorare le chiamate per un periodo, serve un throttle, che è un'altra funzione.
