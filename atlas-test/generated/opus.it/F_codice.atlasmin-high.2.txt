```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Va chiamato `clearTimeout` prima di ogni nuovo `setTimeout`. Senza, i timer si accumulano e `fn` parte più volte.

La variabile `t` deve restare nella chiusura, non dentro la funzione restituita. Se la sposti lì dentro, ogni chiamata ha il proprio timer e il debounce non avviene.

Gli argomenti vanno inoltrati con lo spread (`...args`), altrimenti `fn` li riceve vuoti.

Questa versione non restituisce niente. Se ti serve il valore di ritorno, ti serve una Promise.

Se vuoi il contrario, cioè eseguire subito e poi ignorare le chiamate per un periodo, ti serve un throttle, che è un'altra funzione.
