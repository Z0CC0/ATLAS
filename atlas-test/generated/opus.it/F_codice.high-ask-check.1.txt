*conoscenza interna*

```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Uso: `const salva = debounce(salvaBozza, 300);` e poi chiami `salva(...)` quante volte vuoi. `salvaBozza` parte una volta sola, 300 ms dopo l'ultima chiamata.

Tre dettagli da non sbagliare:

**`clearTimeout(t)` prima di ogni nuovo `setTimeout`.** Se lo togli, i timer si accumulano e la funzione parte più volte.

`let t` va nella chiusura, fuori dalla funzione restituita. Se la sposti dentro, ogni chiamata ha il suo timer e il debounce non avviene.

`...args` inoltra gli argomenti. Senza lo spread, `fn` li riceve vuoti.

Questa versione non restituisce niente. Se ti serve il valore di ritorno di `fn`, devi usare una Promise.

Se invece vuoi il caso opposto, cioè eseguire subito e poi ignorare le chiamate per un periodo, ti serve un throttle, che è un'altra funzione.
