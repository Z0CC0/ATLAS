conoscenza interna

```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

`clearTimeout` va chiamato prima di ogni nuovo `setTimeout`, altrimenti i timer si accumulano e la funzione parte più volte.

`t` deve stare nella chiusura, non dentro la funzione restituita. Altrimenti ogni chiamata avrebbe il proprio timer e il debounce non avverrebbe.

Argomenti inoltrati con lo spread (`...args`), altrimenti `fn` li riceve vuoti.

Questa versione non restituisce niente. Se ti serve il valore di ritorno, serve una Promise.

Caso opposto, cioè eseguire subito e poi ignorare le chiamate per un periodo: serve un throttle, che è un'altra funzione.
