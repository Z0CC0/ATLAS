```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Chiami `clearTimeout` prima di ogni nuovo `setTimeout`. Senza, i timer si accumulano e la funzione parte più volte.

`t` va nella chiusura, non dentro la funzione restituita. Lì ogni chiamata avrebbe il proprio timer e il debounce non avverrebbe.

Inoltri gli argomenti con lo spread (`...args`). Senza, la funzione chiamata li riceve vuoti.

Questa versione non restituisce niente. Se ti serve il valore di ritorno, ti serve una Promise.

Per il caso opposto, cioè eseguire subito e poi ignorare le chiamate per un periodo, ti serve un throttle, che è un'altra funzione.
