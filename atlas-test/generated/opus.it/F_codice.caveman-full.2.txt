Nessuna libreria necessaria. Implementazione:

```js
function debounce(fn, ms) { let t; return (...args) => { clearTimeout(t); t = setTimeout(() => fn(...args), ms); }; }
```

Tre punti da rispettare:

- **`clearTimeout` prima di ogni nuovo `setTimeout`.** Se lo togli, i timer si accumulano e la funzione parte più volte.
- **`t` resta nella chiusura, fuori dalla funzione restituita.** Se la sposti dentro, ogni chiamata ha il proprio timer e il debounce non avviene.
- **Argomenti inoltrati con lo spread (`...args`).** Senza spread, `fn` li riceve vuoti.

Limiti:

- Questa versione non restituisce niente. Se ti serve il valore di ritorno, ti serve una Promise.
- Per il caso opposto, cioè eseguire subito e poi ignorare le chiamate per un periodo, ti serve un throttle. Il throttle è un'altra funzione.
