Ecco l'implementazione:

```js
function debounce(fn, ms) { let t; return (...args) => { clearTimeout(t); t = setTimeout(() => fn(...args), ms); }; }
```

Tre punti da rispettare:

- **`clearTimeout(t)` prima di ogni nuovo `setTimeout`.** Senza, i timer si accumulano e la funzione parte più volte.
- **`let t` nella chiusura, fuori dalla funzione restituita.** Dentro, ogni chiamata avrebbe il proprio timer e il debounce non avverrebbe.
- **Argomenti inoltrati con lo spread (`...args`).** Senza, la funzione chiamata li riceve vuoti.

Limiti:

- Questa versione non restituisce niente. Se ti serve il valore di ritorno, ti serve una Promise.
- Per il caso opposto, cioè eseguire subito e poi ignorare le chiamate per un periodo, ti serve un throttle. Il throttle è un'altra funzione.
