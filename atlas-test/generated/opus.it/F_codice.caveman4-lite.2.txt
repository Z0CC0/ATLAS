Debounce senza librerie:

```js
function debounce(fn, ms) { let t; return (...args) => { clearTimeout(t); t = setTimeout(() => fn(...args), ms); }; }
```

Tre dettagli contano:

- **`clearTimeout` va prima di ogni nuovo `setTimeout`.** Senza, i timer si accumulano e la funzione parte più volte.
- **`t` va nella chiusura, non dentro la funzione restituita.** Altrimenti ogni chiamata ha il suo timer e il debounce non avviene.
- **Gli argomenti vanno inoltrati con lo spread (`...args`).** Altrimenti la funzione chiamata li riceve vuoti.

Limiti:

- Questa versione non restituisce niente. Se ti serve il valore di ritorno, devi usare una Promise.
- Per eseguire subito e poi ignorare le chiamate per un periodo ti serve un throttle. È un'altra funzione.
