Conoscenza interna.

Con `let` puoi riassegnare la variabile, con `const` no.

`const` blocca solo il nome, non il valore. Se dichiari un oggetto con `const`, puoi comunque modificarne il contenuto:

```js
const utente = { nome: "Anna" };
utente.nome = "Luca";   // consentito
utente = {};            // errore: riassegnazione
```

```js
let contatore = 0;
contatore = 1;          // consentito
```

`let` e `const` hanno ambito di blocco, a differenza di `var`.
