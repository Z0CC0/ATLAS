Ecco una funzione `debounce` scritta da zero:

```js
function debounce(fn, ms) { let t; return (...args) => { clearTimeout(t); t = setTimeout(() => fn(...args), ms); }; }
```

Perché funziona:

- **`clearTimeout(t)` prima di ogni nuovo `setTimeout`.** Così ogni chiamata annulla il timer precedente. Senza, i timer si accumulano e la funzione parte più volte.
- **`t` sta nella chiusura**, non dentro la funzione restituita. Se stesse dentro, ogni chiamata avrebbe il proprio timer e il debounce non avverrebbe.
- **Gli argomenti passano con lo spread (`...args`).** Senza spread, `fn` li riceve vuoti.

Questa versione non restituisce niente. Se ti serve il valore di ritorno di `fn`, devi usare una Promise.

Se invece vuoi eseguire subito e poi ignorare le chiamate per un periodo, non ti serve un debounce. Ti serve un throttle, che è un'altra funzione.
