conoscenza interna

Senza librerie basta una funzione che avvolge quella originale:

```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Uso: `const onResize = debounce(ricalcola, 200);`

Tre dettagli la fanno funzionare:

`clearTimeout` va chiamato prima di ogni nuovo `setTimeout`. Altrimenti i timer si accumulano e la funzione parte più volte.

`t` deve stare nella chiusura, non dentro la funzione restituita. Se stesse lì, ogni chiamata avrebbe il proprio timer e il debounce non avverrebbe.

Gli argomenti vanno inoltrati con lo spread (`...args`), altrimenti la funzione chiamata li riceve vuoti.

Limite: questa versione non restituisce niente. Se ti serve il valore di ritorno, devi usare una Promise.

Se invece vuoi eseguire subito e poi ignorare le chiamate per un certo periodo, ti serve un throttle, che è un'altra funzione.
