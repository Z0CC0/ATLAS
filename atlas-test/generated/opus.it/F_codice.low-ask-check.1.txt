Conoscenza interna.

```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Uso: `const salva = debounce(salvaDati, 300);` e poi chiami `salva(...)` quante volte vuoi. `salvaDati` parte una volta sola, 300 ms dopo l'ultima chiamata.

Tre dettagli che lo fanno funzionare:

`clearTimeout(t)` va chiamato prima di ogni nuovo `setTimeout`. Senza, i timer si accumulano e la funzione parte più volte.

`let t` sta nella chiusura, fuori dalla funzione restituita. Se lo metti dentro, ogni chiamata ha il proprio timer e il debounce non avviene.

`...args` inoltra gli argomenti con lo spread. Senza, `fn` li riceve vuoti.

Limite: questa versione non restituisce niente. Se ti serve il valore di ritorno di `fn`, devi usare una Promise.

Se invece vuoi il contrario, cioè eseguire subito e poi ignorare le chiamate per un certo periodo, ti serve un throttle, che è un'altra funzione.
