Differenza principale: riassegnazione.

- `let` permette di riassegnare il nome.
- `const` vieta di riassegnare il nome. Non vieta di modificare il valore.

Quindi un oggetto dichiarato con `const` può cambiare al suo interno:

```js
let n = 1;
n = 2;            // ok

const obj = { a: 1 };
obj.a = 2;        // ok: modifica interna
obj = {};         // errore: riassegnazione
```

In comune: `let` e `const` hanno entrambi ambito di blocco. `var` invece non ce l'ha.
