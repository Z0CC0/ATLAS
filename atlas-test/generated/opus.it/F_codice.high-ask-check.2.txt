conoscenza interna

```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

`clearTimeout` prima di ogni nuovo `setTimeout`: altrimenti i timer si accumulano e la funzione parte più volte.

`t` deve stare nella chiusura, **non** dentro la funzione restituita: altrimenti ogni chiamata ha il proprio timer e il debounce non avviene.

Argomenti inoltrati con lo spread (`...args`): altrimenti la funzione chiamata li riceve vuoti.

Questa versione non restituisce niente. Se ti serve il valore di ritorno, ti serve una Promise.

Se vuoi il caso opposto, cioè eseguire subito e poi ignorare le chiamate per un periodo, ti serve un throttle, che è un'altra funzione.
