Per sito statico, set consigliato:

- **`Strict-Transport-Security`**: `max-age` almeno `31536000` secondi, con `includeSubDomains`. Obbliga browser a usare HTTPS.
- **`Content-Security-Policy`**: `default-src 'self'`. Blocca iniezione di script di terze parti.
- **`X-Content-Type-Options`**: `nosniff`. Browser non indovina tipo di contenuto.
- **`Referrer-Policy`**: `strict-origin-when-cross-origin`. Percorso completo non esce verso altri siti.
- **Anti-clickjacking**: `X-Frame-Options: DENY`, oppure `frame-ancestors 'none'` dentro CSP.
- **`Permissions-Policy`**: spegni camera, microfono, geolocalizzazione se sito non li usa.

```
Strict-Transport-Security: max-age=31536000; includeSubDomains
Content-Security-Policy: default-src 'self'; frame-ancestors 'none'
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
X-Frame-Options: DENY
Permissions-Policy: camera=(), microphone=(), geolocation=()
```

Non mettere `X-XSS-Protection`. Header deprecato: browser moderni lo ignorano, versioni vecchie introducevano vulnerabilità.
