```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Tre punti da rispettare:

- **`clearTimeout` prima di ogni `setTimeout`.** Senza questa chiamata i timer si accumulano e `fn` parte più volte.
- **`t` nella chiusura, fuori dalla funzione restituita.** Se `t` sta dentro, ogni chiamata ha il proprio timer e il debounce non avviene.
- **Argomenti inoltrati con lo spread (`...args`).** Senza spread, `fn` li riceve vuoti.

Limite: questa versione non restituisce niente. Se ti serve il valore di ritorno, usa una Promise.

Vuoi eseguire subito e poi ignorare le chiamate per un periodo? Quello è il caso opposto: serve un throttle, che è un'altra funzione.
