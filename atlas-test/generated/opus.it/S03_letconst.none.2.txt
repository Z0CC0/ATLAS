`let` e `const` hanno in comune l'**ambito di blocco**: una variabile dichiarata con l'uno o con l'altro esiste solo all'interno del blocco `{ ... }` in cui è dichiarata. `var` invece non funziona così.

La differenza sta nella **riassegnazione**.

**`let` permette di riassegnare la variabile:**

```js
let contatore = 0;
contatore = 1; // nessun problema
```

**`const` impedisce di riassegnare il nome:**

```js
const pi = 3.14;
pi = 3; // errore
```

Attenzione però: `const` blocca il nome, non il valore. Se dichiari un oggetto con `const`, puoi comunque cambiarne il contenuto:

```js
const utente = { nome: "Anna" };
utente.nome = "Marco";        // consentito: cambi l'interno dell'oggetto
utente = { nome: "Luca" };    // errore: stai riassegnando il nome
```

In pratica, usa `const` quando il nome deve indicare sempre lo stesso valore. Usa `let` quando prevedi di riassegnarlo.
