conoscenza interna

Usa una chiusura che tiene un timer e lo azzera a ogni chiamata:

```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Chiama `clearTimeout` prima di ogni nuovo `setTimeout`, altrimenti i timer si accumulano e la funzione parte più volte.

Tieni `t` nella chiusura, non dentro la funzione restituita. Se no, ogni chiamata avrebbe il proprio timer e il debounce non avverrebbe.

Inoltra gli argomenti con lo spread (`...args`), altrimenti la funzione chiamata li riceve vuoti.

Questa versione non restituisce niente. Se ti serve il valore di ritorno, ti serve una Promise.

Per il caso opposto, cioè eseguire subito e poi ignorare le chiamate per un periodo, ti serve un throttle, che è un'altra funzione.
