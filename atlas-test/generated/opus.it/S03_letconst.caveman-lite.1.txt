La differenza principale riguarda la riassegnazione.

- **`let`** permette di riassegnare la variabile.
- **`const`** impedisce di riassegnare il nome, ma non impedisce di modificare il valore. Per questo un oggetto dichiarato con `const` può cambiare al suo interno.

```js
let contatore = 1;
contatore = 2;          // ok

const utente = { nome: "Ada" };
utente.nome = "Grace";  // ok: l'oggetto cambia al suo interno
utente = {};            // TypeError: il nome non si può riassegnare
```

`let` e `const` hanno anche un punto in comune: entrambi hanno ambito di blocco, a differenza di `var`.
