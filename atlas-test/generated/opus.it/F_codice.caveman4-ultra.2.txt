```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Punti chiave:
- **`clearTimeout(t)` prima di ogni nuovo `setTimeout`.** Senza, i timer si accumulano e `fn` parte più volte.
- **`let t` sta nella chiusura**, fuori dalla funzione restituita. Se lo metti dentro, ogni chiamata ha il suo timer e il debounce non avviene.
- **`...args` con lo spread.** Senza, `fn` riceve argomenti vuoti.

Limiti:
- Non restituisce niente. Se ti serve il valore di ritorno di `fn`, ti serve una Promise.
- Per eseguire subito e poi ignorare le chiamate per un periodo, ti serve un throttle, che è un'altra funzione.
