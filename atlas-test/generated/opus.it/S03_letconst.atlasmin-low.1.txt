`let` permette di riassegnare la variabile, `const` no.

Con `const` il nome resta legato sempre allo stesso valore, ma quel valore si può comunque modificare. Un oggetto dichiarato con `const` può cambiare al suo interno:

```js
const utente = { nome: "Anna" };
utente.nome = "Luca";   // consentito
utente = {};            // errore: riassegnazione

let contatore = 0;
contatore = 1;          // consentito
```

In comune hanno l'ambito di blocco: esistono solo dentro le `{}` in cui sono dichiarati, a differenza di `var`.
