```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Uso: `const onResize = debounce(handler, 200);`

Tre cose da rispettare:
- **Chiama `clearTimeout(t)` prima di ogni nuovo `setTimeout`.** Senza questa chiamata i timer si accumulano e `fn` parte più volte.
- **Dichiara `t` nella chiusura, fuori dalla funzione restituita.** Dentro, ogni chiamata ha il proprio timer e il debounce non avviene.
- **Inoltra gli argomenti con lo spread `...args`.** Senza spread, `fn` li riceve vuoti.

Limiti:
- Questa versione non restituisce niente. Se ti serve il valore di ritorno di `fn`, usa una Promise.
- Se vuoi il comportamento opposto, cioè eseguire subito e poi ignorare le chiamate per un periodo, ti serve un throttle. Il throttle è un'altra funzione.
