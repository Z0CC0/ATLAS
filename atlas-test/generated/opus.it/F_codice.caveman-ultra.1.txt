Senza librerie basta una chiusura con un timer:

```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Tre dettagli la fanno funzionare:

- **`clearTimeout` prima di ogni nuovo `setTimeout`.** Senza, i timer si accumulano e la funzione parte più volte.
- **`t` nella chiusura, non dentro la funzione restituita.** Dentro, ogni chiamata avrebbe il proprio timer e il debounce non avverrebbe.
- **Argomenti inoltrati con lo spread (`...args`).** Senza, la funzione chiamata li riceve vuoti.

Questa versione non restituisce niente. Se ti serve il valore di ritorno, devi usare una Promise.

Se invece vuoi eseguire subito e poi ignorare le chiamate per un periodo, ti serve un throttle. È un'altra funzione.
