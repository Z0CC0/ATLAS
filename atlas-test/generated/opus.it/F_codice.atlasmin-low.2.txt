Avvolgi la funzione in una chiusura che azzera il timer a ogni chiamata:

```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Uso:

```js
const onResize = debounce(() => console.log('resize'), 200);
window.addEventListener('resize', onResize);
```

Tre punti da rispettare, altrimenti non funziona:

`clearTimeout` va chiamato prima di ogni nuovo `setTimeout`. Senza, i timer si accumulano e la funzione parte più volte.

`t` deve stare nella chiusura, non dentro la funzione restituita. Se no ogni chiamata ha il proprio timer e il debounce non avviene.

Argomenti inoltrati con lo spread (`...args`). Senza, `fn` li riceve vuoti.

Questa versione non restituisce niente. Se ti serve il valore di ritorno, devi usare una Promise.

Se invece vuoi eseguire subito e poi ignorare le chiamate per un certo periodo, ti serve un throttle, che è un'altra funzione.
