Set these six, plain prose since it is security guidance:

Strict-Transport-Security with max-age of at least 31536000 seconds and includeSubDomains. This forces the browser onto HTTPS for the domain and every subdomain.

Content-Security-Policy with default-src 'self'. This is what blocks third-party script injection, since the page can only load resources from its own origin.

X-Content-Type-Options set to nosniff. This stops the browser from guessing the content type of a response.

Referrer-Policy set to strict-origin-when-cross-origin. This keeps the full path from leaking to other sites in the Referer header.

X-Frame-Options set to DENY, or frame-ancestors 'none' inside the Content-Security-Policy. Either one protects against clickjacking.

Permissions-Policy switching off camera, microphone and geolocation, if the site does not use them.

Omit X-XSS-Protection. It is deprecated: modern browsers ignore it, and older versions introduced vulnerabilities.
