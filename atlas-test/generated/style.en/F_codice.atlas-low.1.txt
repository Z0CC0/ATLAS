```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Three things in there matter.

`clearTimeout(t)` must run before every new `setTimeout`, or timers pile up and `fn` fires more than once.

`t` must live in closure, not inside returned function, or every call gets its own timer and nothing gets debounced.

Arguments must be forwarded with spread, or `fn` receives nothing.

Returned function returns nothing: if return value matters, you need a Promise.

Opposite case, run immediately then ignore calls for a period, is a throttle, a different function.
