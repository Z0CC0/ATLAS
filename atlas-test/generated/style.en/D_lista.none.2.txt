For a static-only site, six headers do the job, and one old one should be left out.

- **Strict-Transport-Security** with a max-age of at least one year, 31536000 seconds, plus includeSubDomains. This forces the browser onto HTTPS for every later visit.
- **Content-Security-Policy** with default-src 'self'. This is the header that blocks third-party script injection, so it matters even when you serve no scripts of your own.
- **X-Content-Type-Options** set to nosniff. The browser then trusts your declared content type instead of guessing it.
- **Referrer-Policy** set to strict-origin-when-cross-origin. Other sites see only your origin, never the full path of the page the visitor came from.
- **X-Frame-Options** set to DENY, or frame-ancestors 'none' inside the Content-Security-Policy. Either one stops clickjacking by refusing to let your pages load in a frame.
- **Permissions-Policy** switching off camera, microphone and geolocation, assuming a static site has no use for them.

Omit X-XSS-Protection. It is deprecated, modern browsers ignore it, and older versions introduced vulnerabilities of their own.

Put together, the set looks like this:

```
Strict-Transport-Security: max-age=31536000; includeSubDomains
Content-Security-Policy: default-src 'self'; frame-ancestors 'none'
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
X-Frame-Options: DENY
Permissions-Policy: camera=(), microphone=(), geolocation=()
```
