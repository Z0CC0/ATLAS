Cache keeps the already-processed prefix of a request; later requests starting the same way skip paying for it. Prefix only: one different character at the start, no reuse from that point on. Stable parts first, changing parts after, never the reverse. A system line changing every turn, such as a clock, kills reuse of everything after it.

Cache write costs more than a normal read, so the first request is more expensive. Gain starts from the second request, grows with number of turns.

Pays off: long conversations with large stable context: system instructions, attached documentation, tool definitions.

Does not pay off: single requests differing from each other: write paid, never read back.
