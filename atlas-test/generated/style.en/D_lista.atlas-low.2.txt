Six headers to set, and one to leave out.

Strict-Transport-Security with a max-age of at least 31536000 seconds and includeSubDomains. This forces the browser onto HTTPS.

Content-Security-Policy with default-src 'self'. This is what blocks third-party script injection.

X-Content-Type-Options set to nosniff, so the browser does not guess the content type.

Referrer-Policy set to strict-origin-when-cross-origin, so the full path does not leak to other sites.

X-Frame-Options set to DENY, or frame-ancestors 'none' inside the Content-Security-Policy, against clickjacking.

Permissions-Policy switching off camera, microphone and geolocation, if the site does not use them.

Omit X-XSS-Protection. It is deprecated: modern browsers ignore it, and older versions introduced vulnerabilities.
