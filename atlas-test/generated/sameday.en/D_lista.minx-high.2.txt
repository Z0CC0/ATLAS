Set these six headers, and leave out X-XSS-Protection.

Strict-Transport-Security with a max-age of at least 31536000 seconds and includeSubDomains, so the browser always uses HTTPS.

Content-Security-Policy with default-src 'self', which blocks injected third-party scripts.

X-Content-Type-Options: nosniff, so the browser does not guess the content type.

Referrer-Policy: strict-origin-when-cross-origin, so the full path does not leak to other sites.

X-Frame-Options: DENY against clickjacking. You can use frame-ancestors 'none' inside the Content-Security-Policy instead.

Permissions-Policy to turn off camera, microphone and geolocation if the site does not use them.

Do not send X-XSS-Protection. It is deprecated, modern browsers ignore it, and older browsers that honoured it could be made vulnerable by it.

```
Strict-Transport-Security: max-age=31536000; includeSubDomains
Content-Security-Policy: default-src 'self'; frame-ancestors 'none'
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
X-Frame-Options: DENY
Permissions-Policy: camera=(), microphone=(), geolocation=()
```
