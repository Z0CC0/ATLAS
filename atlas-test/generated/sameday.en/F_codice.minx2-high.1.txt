```js
function debounce(fn, ms) { let t; return (...args) => { clearTimeout(t); t = setTimeout(() => fn(...args), ms); }; }
```

Call `clearTimeout` before every new `setTimeout`. Without it, timers pile up and `fn` fires more than once.

Keep `t` in the closure, not inside the returned function. If `t` lives inside, every call gets its own timer and nothing is debounced.

Forward arguments with the spread (`...args`), or `fn` receives nothing.

This version returns nothing. If you need the return value, use a Promise.

To run immediately and then ignore calls for a while, you want a throttle, which is a different function.
