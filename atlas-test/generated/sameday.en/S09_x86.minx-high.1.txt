x86 grew from a 16-bit chip into a compatible interface on top of an increasingly complex hidden machine.

8086, 1978: 16 bit, grown out of 8080, source-compatible with it.

80286, 1982: protected mode. No way back to real mode without reboot.

80386, 1985: 32 bit, paged virtual memory, virtual 8086 mode.

486, 1989: first-level cache and maths coprocessor pulled onto chip.

Pentium, 1993: superscalar. Two integer pipelines, up to two instructions retired per cycle.

Pentium Pro, 1995: out-of-order execution. x86 instructions translated into internal micro-operations. From here x86 is an interface, no longer the real machine underneath.

Pentium 4, 2000: very long pipeline chasing frequency. Hits power wall.

AMD64, 2003: AMD extends architecture to 64 bit, Intel adopts same instruction set. First time dominant extension does not come from Intel.

Core 2, 2006: direction shifts from frequency to core count.

Vector extensions grow across generations: MMX, SSE, AVX, AVX-512.

Today: complexity sits in layers below. Branch prediction, cache hierarchy, speculative execution.

Spectre and Meltdown, 2018: speculative execution carried security cost nobody had priced.
