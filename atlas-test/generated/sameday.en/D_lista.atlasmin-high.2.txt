For a static site, set these six headers and leave out X-XSS-Protection:

`Strict-Transport-Security: max-age=31536000; includeSubDomains` forces the browser onto HTTPS. Use a max-age of at least 31536000 seconds.

`Content-Security-Policy: default-src 'self'` blocks third-party script injection.

`X-Content-Type-Options: nosniff` stops the browser from guessing the content type.

`Referrer-Policy: strict-origin-when-cross-origin` keeps your full path from leaking to other sites.

`X-Frame-Options: DENY` protects against clickjacking. You can use `frame-ancestors 'none'` inside the Content-Security-Policy instead.

`Permissions-Policy: camera=(), microphone=(), geolocation=()` switches off the camera, microphone and geolocation. Set it only if the site doesn't use them.

**Don't send `X-XSS-Protection`.** It's deprecated. Modern browsers ignore it, and older versions introduced vulnerabilities.

Taken together:

```
Strict-Transport-Security: max-age=31536000; includeSubDomains
Content-Security-Policy: default-src 'self'; frame-ancestors 'none'
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
X-Frame-Options: DENY
Permissions-Policy: camera=(), microphone=(), geolocation=()
```
