```js
function debounce(fn, ms) { let t; return (...args) => { clearTimeout(t); t = setTimeout(() => fn(...args), ms); }; }
```

Always call `clearTimeout` before each new `setTimeout`. Without it, timers pile up and the function fires more than once.

Keep `t` in the closure, not inside the returned function. Otherwise every call gets its own timer and nothing is debounced.

Pass the arguments on with the spread (`...args`), or `fn` receives nothing.

This version returns nothing. If you need the return value, use a Promise.

If you want the opposite, running at once and then ignoring calls for a while, that's a throttle, which is a different function.
