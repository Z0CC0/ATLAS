Direct `ALTER TABLE ... ALTER COLUMN TYPE integer` rewrites the whole table under an ACCESS EXCLUSIVE lock — service down for the entire duration. Do it this way instead:

1. Check every existing value is convertible: count rows where the column isn't all digits.

2. Add the new column: `ALTER TABLE t ADD COLUMN colonna_int integer`.

3. Fill it in batches of ten thousand rows, so no long lock is held on the table.

4. Add a trigger keeping the old and new columns in sync during the migration.

5. Change the code to read from the new column, and ship it.

6. Only then, drop the old column: `ALTER TABLE t DROP COLUMN colonna`.

Step 6 is irreversible — once dropped, the data doesn't come back without a restore from backup.
