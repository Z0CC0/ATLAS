All seven headers below apply to a static site. Six should be set, and X-XSS-Protection should be left out.

```
Strict-Transport-Security: max-age=31536000; includeSubDomains
Content-Security-Policy: default-src 'self'; frame-ancestors 'none'
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
X-Frame-Options: DENY
Permissions-Policy: camera=(), microphone=(), geolocation=()
```

**Strict-Transport-Security** makes the browser use HTTPS. Set max-age to at least 31536000 seconds and include includeSubDomains.

**Content-Security-Policy** with default-src 'self' is the header that blocks third-party scripts from being injected into your pages.

X-Content-Type-Options: nosniff stops the browser from guessing the content type.

Referrer-Policy: strict-origin-when-cross-origin keeps the full path from leaking to other sites.

X-Frame-Options: DENY protects against clickjacking. You can use frame-ancestors 'none' inside the Content-Security-Policy instead. The block above sets both.

Permissions-Policy turns off the camera, microphone and geolocation. Set it only if your site doesn't use those features.

Don't set X-XSS-Protection. It's deprecated, modern browsers ignore it, and older browser versions that supported it introduced vulnerabilities.
