8086, 1978: 16-bit, grows from 8080, source-compatible.

80286, 1982: protected mode added. No return to real mode without reboot.

80386, 1985: 32-bit. Paged virtual memory. Virtual 8086 mode.

486, 1989: L1 cache and FPU move onto the chip.

Pentium, 1993: superscalar, two integer pipelines, two instructions retired per cycle.

Pentium Pro, 1995: out-of-order execution. x86 instructions decoded into internal micro-ops. From here x86 is an interface, not the real machine underneath.

Pentium 4, 2000: chases frequency, very long pipeline, hits the power wall.

2003: AMD extends to 64-bit with AMD64. Intel adopts it. First time the dominant extension isn't Intel's.

Core 2, 2006: direction shifts, frequency to core count.

Across generations: vector extensions grow — MMX, SSE, AVX, AVX-512.

Today: complexity lives below the ISA — branch prediction, cache hierarchy, speculative execution.

Spectre and Meltdown, 2018: speculative execution had a security cost nobody had priced.
