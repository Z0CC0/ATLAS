Set these on every static page:

Strict-Transport-Security, max-age at least 31536000, includeSubDomains — forces HTTPS.

Content-Security-Policy with default-src 'self' — blocks third-party script injection. Add frame-ancestors 'none' here instead of X-Frame-Options if you only need one.

X-Content-Type-Options: nosniff — stops content-type guessing.

Referrer-Policy: strict-origin-when-cross-origin — keeps full path from leaking cross-site.

X-Frame-Options: DENY — clickjacking protection (redundant with frame-ancestors 'none', pick one).

Permissions-Policy disabling camera, microphone, geolocation if unused.

Omit X-XSS-Protection — deprecated, ignored by modern browsers, caused vulnerabilities in old ones.
