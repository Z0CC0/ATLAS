8086, 1978: 16 bit, grows out of 8080, source-level compatible — start of line.

80286, 1982: adds protected mode. Flaw — no way back to real mode without reboot.

80386, 1985: jumps to 32 bit, paged virtual memory, virtual 8086 mode.

486, 1989: pulls first-level cache and math coprocessor onto chip itself.

Pentium, 1993: superscalar — two integer pipelines, two instructions retired per cycle.

Pentium Pro, 1995: turning point. Out-of-order execution, translates x86 into internal micro-ops. From here x86 just interface, not real machine underneath — silicon runs something else, x86 only façade.

Pentium 4, 2000: chases frequency, very long pipeline, hits power wall.

2003: AMD extends to 64 bit with AMD64, Intel adopts same set. First time dominant extension not from Intel.

2006, Core 2: direction shifts, frequency to core count.

Across generations, vector extensions grow: MMX, SSE, AVX, AVX-512.

Today complexity not in ISA — sits below: branch prediction, cache hierarchy, speculative execution.

2018: Spectre and Meltdown show speculative execution had security cost nobody priced.
