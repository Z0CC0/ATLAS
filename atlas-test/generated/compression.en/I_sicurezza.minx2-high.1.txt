No. Anything that reaches the browser can be read. Obfuscation falls apart as soon as someone opens the developer tools or looks at the network requests.

Keep the key on the server. Your frontend calls an endpoint on your own backend, and that backend calls the service with the key.

Put a rate limit on that backend endpoint. Without one, anyone can use it to spend your key for free.

If the key has already been published, treat it as compromised and rotate it right away. Removing it from the code isn't enough.

Deleting it in a new commit doesn't fix it either. The key stays in the repository history, and anyone who already has a clone has the key.
