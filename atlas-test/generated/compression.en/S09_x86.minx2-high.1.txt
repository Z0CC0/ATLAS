8086, 1978: 16 bit, grown out of 8080, compatible at source level.

80286, 1982: protected mode, but no way back to real mode without reboot.

80386, 1985: 32 bit, paged virtual memory, virtual 8086 mode.

486, 1989: first-level cache and maths coprocessor pulled onto chip.

Pentium, 1993: superscalar, two integer pipelines, can retire two instructions per cycle.

Pentium Pro, 1995: out-of-order execution, x86 instructions translated into internal micro-operations. **From here x86 is an interface, no longer the real machine underneath.**

Pentium 4, 2000: very long pipeline chasing frequency, hits power wall.

2003: AMD extends architecture to 64 bit with AMD64, Intel adopts same instruction set. First time dominant extension does not come from Intel.

2006, Core 2: direction shifts from frequency to core count.

Across generations, vector extensions grow: MMX, SSE, AVX, AVX-512.

Today complexity sits in layers below: branch prediction, cache hierarchy, speculative execution.

2018: Spectre and Meltdown show speculative execution carried security cost nobody had priced.
