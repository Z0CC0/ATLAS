```js
function debounce(fn, ms) { let t; return (...args) => { clearTimeout(t); t = setTimeout(() => fn(...args), ms); }; }
```

Call `clearTimeout` before every new `setTimeout`. Otherwise timers pile up and `fn` fires more than once.

Keep `t` in the closure, not inside the returned function. Otherwise each call gets its own timer and nothing is debounced.

Pass the arguments on with the spread (`...args`). Otherwise `fn` receives nothing.

This version returns nothing. If you need the return value, use a Promise.

If you want the opposite, running right away and then ignoring calls for a while, you need a throttle. That's a different function.
