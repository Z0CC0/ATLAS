8086, 1978: 16 bit, grows out of 8080, source-level compatible. Base of everything after.

80286, 1982: adds protected mode — but no way back to real mode without reboot.

80386, 1985: 32 bit arrives, plus paged virtual memory and virtual 8086 mode.

486, 1989: first-level cache and math coprocessor move onto chip.

Pentium, 1993: superscalar — two integer pipelines, two instructions retire per cycle.

Pentium Pro, 1995: out-of-order execution, x86 instructions translated into internal micro-ops. From here x86 becomes interface only, not real machine underneath.

Pentium 4, 2000: chases frequency with very long pipeline, hits power wall.

2003: AMD extends architecture to 64 bit with AMD64, Intel adopts same instruction set. First time dominant extension doesn't come from Intel.

2006, Core 2: direction shifts from frequency to core count.

Alongside: vector extensions grow across generations — MMX, SSE, AVX, AVX-512.

Today complexity sits below visible architecture: branch prediction, cache hierarchy, speculative execution.

2018: Spectre and Meltdown show speculative execution carried security cost nobody had priced.
