8086 (1978): 16-bit, grow from 8080, source-compatible.

80286 (1982): protected mode arrive. No way back to real mode without reboot.

80386 (1985): 32-bit. Paged virtual memory. Virtual 8086 mode.

486 (1989): first-level cache and math coprocessor move onto chip.

Pentium (1993): superscalar. Two integer pipelines, two instructions retire per cycle.

Pentium Pro (1995): out-of-order execution arrive. x86 instructions translate into internal micro-operations. From here x86 only interface — not real machine underneath anymore.

Pentium 4 (2000): chase frequency, very long pipeline, hit power wall.

2003: AMD extend architecture to 64-bit with AMD64. Intel adopt same instruction set. First time dominant extension not come from Intel.

2006 (Core 2): direction shift, frequency to core count.

Vector extensions grow across generations: MMX, SSE, AVX, AVX-512.

Today: complexity sit in layers below — branch prediction, cache hierarchy, speculative execution.

2018: Spectre and Meltdown show speculative execution carry security cost nobody priced.
