8086, 1978: 16 bit, grow from 8080, source-level compatible.

80286, 1982: protected mode arrive. No way back to real mode without reboot.

80386, 1985: 32 bit. Paged virtual memory. Virtual 8086 mode.

486, 1989: L1 cache and math coprocessor move onto chip.

Pentium, 1993: superscalar. Two integer pipelines, two instructions retire per cycle.

Pentium Pro, 1995: out-of-order execution arrive. x86 instructions translate to internal micro-ops. From here x86 just interface, not real machine underneath.

Pentium 4, 2000: chase frequency, very long pipeline, hit power wall.

2003: AMD extend to 64 bit with AMD64. Intel adopt same instruction set. First time dominant extension not come from Intel.

2006, Core 2: direction shift, frequency to core count.

Vector extensions grow across generations: MMX, SSE, AVX, AVX-512.

Today: complexity sit below surface — branch prediction, cache hierarchy, speculative execution.

Spectre and Meltdown, 2018: speculative execution carried security cost, nobody priced it before.
