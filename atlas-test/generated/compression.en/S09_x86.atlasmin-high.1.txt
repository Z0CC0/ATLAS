1978, 8086: 16 bit, grown from 8080, source-compatible with it.

1982, 80286: protected mode arrives. No way back to real mode without reboot.

1985, 80386: 32 bit, paged virtual memory, virtual 8086 mode.

1989, 486: L1 cache and FPU move onto the chip.

1993, Pentium: superscalar, two integer pipelines, two instructions retired per cycle.

1995, Pentium Pro: out-of-order execution, x86 translated into internal micro-ops. From here x86 is an interface, not the real machine underneath.

2000, Pentium 4: chases frequency, very long pipeline, hits the power wall.

2003: AMD extends x86 to 64 bit with AMD64, Intel adopts it. First time the dominant extension doesn't come from Intel.

2006, Core 2: direction shifts from frequency to core count.

Across generations, vector extensions grow: MMX, SSE, AVX, AVX-512.

Today the complexity sits below the ISA: branch prediction, cache hierarchy, speculative execution.

2018: Spectre and Meltdown show speculative execution carried a security cost nobody had priced.
