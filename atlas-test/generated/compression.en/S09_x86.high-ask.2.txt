8086, 1978: 16 bit, grown from 8080, source-compatible.
80286, 1982: protected mode. No return to real mode without reboot.
80386, 1985: 32 bit, paged virtual memory, virtual 8086 mode.
486, 1989: L1 cache and FPU onto chip.
Pentium, 1993: superscalar. Two integer pipelines, two instructions retired per cycle.
Pentium Pro, 1995: out-of-order execution. x86 translated to internal micro-ops. From here x86 is interface only, not the real machine underneath.
Pentium 4, 2000: chases frequency, very long pipeline, hits the power wall.
2003: AMD extends to 64 bit with AMD64. Intel adopts it. First time the dominant extension isn't Intel's.
2006, Core 2: direction shifts, frequency to core count.
Vector extensions grow across generations: MMX, SSE, AVX, AVX-512.
Today: complexity sits below — branch prediction, cache hierarchy, speculative execution.
2018: Spectre and Meltdown. Speculative execution's security cost, unpriced until then.
