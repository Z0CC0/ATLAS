Set these six headers on every response, and leave out X-XSS-Protection:

```
Strict-Transport-Security: max-age=31536000; includeSubDomains
Content-Security-Policy: default-src 'self'; frame-ancestors 'none'
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
X-Frame-Options: DENY
Permissions-Policy: camera=(), microphone=(), geolocation=()
```

Strict-Transport-Security forces the browser onto HTTPS. Use a max-age of at least 31536000 seconds and include includeSubDomains.

Content-Security-Policy with default-src 'self' is the header that blocks third-party script injection.

X-Content-Type-Options: nosniff stops the browser from guessing the content type.

Referrer-Policy: strict-origin-when-cross-origin keeps the full path from leaking to other sites.

X-Frame-Options: DENY protects against clickjacking. frame-ancestors 'none' inside the Content-Security-Policy does the same job, so either one is enough. The block above sets both.

Permissions-Policy turns off camera, microphone and geolocation. Keep it this way only if the site doesn't use those features.

Don't set X-XSS-Protection. It's deprecated, modern browsers ignore it, and in older browsers it introduced vulnerabilities.
