1978, 8086: 16 bit, grows out of 8080, source-level compatible.

1982, 80286: protected mode arrives — but no path back to real mode short of reboot. Half a step.

1985, 80386: real jump — 32 bit, paged virtual memory, virtual 8086 mode. Foundation for everything after.

1989, 486: L1 cache and math coprocessor move onto die. Integration starts.

1993, Pentium: superscalar — two integer pipelines, two instructions retired per cycle.

1995, Pentium Pro: out-of-order execution, x86 instructions translated into internal micro-ops. Turning point — from here x86 just interface, not real machine underneath. Chip does something else internally, translates on the fly.

2000, Pentium 4: frequency chase, very long pipeline, hits power wall. Dead end of that strategy.

2003, AMD64: AMD extends to 64 bit, Intel adopts same instruction set. First time dominant extension not from Intel — role reversal.

2006, Core 2: direction shifts, frequency to core count. Power wall forces new axis of scaling.

Parallel thread throughout: vector extensions grow generation to generation — MMX, SSE, AVX, AVX-512.

Today: complexity lives below the interface — branch prediction, cache hierarchy, speculative execution. x86 as seen from outside barely changed in shape; machine underneath unrecognizable from 1978.

2018, Spectre and Meltdown: bill comes due — speculative execution carried security cost nobody priced in.
