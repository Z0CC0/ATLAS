For a static site, here's what to set:

**Strict-Transport-Security**: `max-age=31536000; includeSubDomains` — this forces the browser onto HTTPS, so use at least 31536000 seconds (one year).

**Content-Security-Policy**: `default-src 'self'` — this is what blocks third-party script injection.

**X-Content-Type-Options**: `nosniff` — stops the browser from guessing the content type of a response.

**Referrer-Policy**: `strict-origin-when-cross-origin` — so the full path doesn't leak to other sites when a visitor clicks off your pages.

**X-Frame-Options**: `DENY` (or, equivalently, `frame-ancestors 'none'` inside the CSP) — protects against clickjacking.

**Permissions-Policy**: switch off camera, microphone, and geolocation if the site doesn't use them.

One thing to explicitly *not* set: **X-XSS-Protection**. It's deprecated — modern browsers ignore it, and older browser versions actually had vulnerabilities introduced by it — so leave it out entirely.
