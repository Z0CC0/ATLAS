Set these six headers on a static site, and leave out X-XSS-Protection.

Strict-Transport-Security with a max-age of at least 31536000 seconds and includeSubDomains. This forces the browser onto HTTPS.

Content-Security-Policy with `default-src 'self'`. This is the header that blocks third-party script injection.

X-Content-Type-Options set to `nosniff`. This stops the browser from guessing the content type.

Referrer-Policy set to `strict-origin-when-cross-origin`. This keeps the full path from leaking to other sites.

X-Frame-Options set to `DENY` protects against clickjacking. You can instead add `frame-ancestors 'none'` to the Content-Security-Policy.

Permissions-Policy turns off camera, microphone and geolocation. Do this only if the site doesn't use those features.

**Don't set X-XSS-Protection.** It's deprecated: modern browsers ignore it, and older versions of it introduced vulnerabilities of their own.
