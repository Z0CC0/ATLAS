8086, 1978: 16-bit, grown from the 8080, source-compatible with it.

80286, 1982: protected mode arrives. No way back to real mode without a reboot.

80386, 1985: 32-bit. Paged virtual memory, virtual 8086 mode.

486, 1989: L1 cache and the math coprocessor move onto the chip.

Pentium, 1993: superscalar. Two integer pipelines, two instructions retired per cycle.

Pentium Pro, 1995: out-of-order execution. x86 instructions get translated into internal micro-ops. From here on, x86 is an interface — not the real machine underneath.

Pentium 4, 2000: chases frequency with a very long pipeline. Hits the power wall.

2003: AMD extends the architecture to 64-bit with AMD64. Intel adopts it. First time the dominant extension doesn't come from Intel.

Core 2, 2006: direction shifts, frequency to core count.

Vector extensions grow alongside all this: MMX, SSE, AVX, AVX-512.

Today the complexity sits below the ISA: branch prediction, cache hierarchy, speculative execution.

Spectre and Meltdown, 2018: speculative execution had a security cost nobody had priced.
