x86 starts in 1978, a little before the eighties. Its history has three phases. First it grows wider and gains protection. Then it becomes a front end for a different machine underneath. Then the gains come from parallelism and from the hidden layers.

**Foundations (1978–1985)**
- **8086 (1978):** 16 bit. Grows out of the 8080 and is compatible with it at source level. That set the pattern of never breaking old code.
- **80286 (1982):** brings protected mode. Flaw: there is no way back to real mode without a reboot.
- **80386 (1985):** the real turning point. It brings 32 bit, paged virtual memory and virtual 8086 mode. Virtual 8086 mode let old 16-bit code run inside the protected world, which fixed the 286's one-way trap.

**Integration and parallelism (1989–1995)**
- **486 (1989):** moves the first level cache and the maths coprocessor onto the chip.
- **Pentium (1993):** superscalar. Two integer pipelines can retire two instructions per cycle.
- **Pentium Pro (1995):** the deepest change. It brings out of order execution and translates x86 instructions into internal micro-operations. From here on, x86 is an interface, not the real machine underneath.

**Frequency hits a limit (2000)**
- **Pentium 4 (2000):** chases clock speed with a very long pipeline. It runs into the power wall.

**Leadership changes hands (2003)**
- **AMD64 (2003):** AMD extends the architecture to 64 bit, and Intel adopts the same instruction set. This is the first time the dominant extension does not come from Intel.

**More cores instead of more speed (2006 onward)**
- **Core 2 (2006):** the direction moves from frequency to core count.
- Vector extensions grow across generations: MMX, SSE, AVX, AVX-512.

**Today**
The complexity now sits in the layers below the instruction set: branch prediction, cache hierarchy and speculative execution. **Spectre and Meltdown (2018)** showed that speculative execution carried a security cost nobody had priced. The same hidden machinery that the Pentium Pro started was now a weak point.

Short version: the instruction set stayed compatible for decades. The machine underneath was rebuilt again and again, and the 2018 attacks showed what that hidden machine could cost.
