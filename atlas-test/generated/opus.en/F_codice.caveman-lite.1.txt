Use a closure that holds one timer. Each call cancels the old timer and starts a new one:

```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Usage:

```js
const onResize = debounce(() => console.log('resized'), 200);
window.addEventListener('resize', onResize);
```

Why it works:

- **`clearTimeout(t)` must run before every new `setTimeout`.** If you skip it, the timers pile up and `fn` fires more than once.
- **`let t` must stay in the closure, outside the returned function.** If you move it inside, every call gets its own timer and nothing is debounced.
- **The spread (`...args`) passes the arguments on.** Without it, `fn` is called with no arguments.

Limits:

- This version returns nothing. If you need `fn`'s return value, wrap the call in a Promise.
- If you want the opposite, where the function runs right away and then ignores calls for a period, you need a throttle. A throttle is a different function.
