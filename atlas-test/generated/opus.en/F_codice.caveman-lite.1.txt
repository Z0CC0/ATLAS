Wrap the function in a closure that holds one timer. Reset that timer on every call:

```javascript
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Usage:

```javascript
const onResize = debounce(() => console.log('resized'), 200);
window.addEventListener('resize', onResize);
```

What makes it work:

- **`clearTimeout(t)` runs before every new `setTimeout`.** This cancels the pending call. Without it, timers pile up and `fn` fires more than once.
- **`t` lives in the closure, outside the returned function.** All calls share one timer. If you declare `t` inside the returned function, every call gets its own timer, and no debouncing happens.
- **`...args` forwards the arguments.** Without the spread, `fn` receives nothing.

Limits:

- **This version returns nothing.** If you need `fn`'s return value, wrap the debounced call in a Promise.
- **It runs only after calls stop for `ms`.** If you want the opposite, where the function runs immediately and then ignores calls for a period, you want a throttle. A throttle is a different function.
