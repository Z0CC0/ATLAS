For a static site, set these six headers:

Strict-Transport-Security: max-age=31536000; includeSubDomains — forces the browser onto HTTPS. Use a max-age of at least 31536000 seconds.

Content-Security-Policy: default-src 'self' — blocks third-party script injection.

X-Content-Type-Options: nosniff — stops the browser from guessing the content type.

Referrer-Policy: strict-origin-when-cross-origin — keeps the full path from leaking to other sites.

X-Frame-Options: DENY — protects against clickjacking. You can instead add frame-ancestors 'none' to the Content-Security-Policy.

Permissions-Policy: camera=(), microphone=(), geolocation=() — switches off those features. Only do this if the site doesn't use them.

Don't set X-XSS-Protection. It's deprecated, modern browsers ignore it, and older versions introduced vulnerabilities.
