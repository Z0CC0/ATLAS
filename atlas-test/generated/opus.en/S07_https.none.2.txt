HTTPS is ordinary HTTP sent through a channel that TLS encrypts. The requests and responses are the same as plain HTTP. What changes is that, before any of them are sent, the browser and the server run a short negotiation called the handshake, which sets up a secure connection.

**1. Hello.** Your browser (the client) opens the connection and lists the TLS versions and ciphers it supports.

**2. The server answers.** The server picks a version and a cipher from that list. It also sends its certificate.

**3. Checking the certificate.** The certificate links a domain name, such as `example.com`, to a public key. A certificate authority (CA) signs it. To check that signature, the browser follows the chain of signatures up until it reaches a root certificate it already has installed. If the chain ends at one of those trusted roots, the browser accepts that this key really belongs to this domain.

**4. Agreeing on a session key.** The client and server then agree on a shared session key. Today this is usually done with an elliptic curve Diffie-Hellman exchange. The session key is symmetric, meaning the same key encrypts and decrypts. That's because asymmetric (public-key) encryption is too expensive to use on all the real traffic. Public-key cryptography is used to set up the connection safely, and the cheaper symmetric key handles the data.

**5. Protected traffic.** From then on, all traffic is encrypted and authenticated. Anyone sitting between you and the server can't read it, and they can't change it without being detected.

**Speed:** The handshake costs round trips before any data moves. TLS 1.2 needs two round trips. TLS 1.3 needs only one, which is one reason connections feel faster with it.

**A common misunderstanding:** A valid certificate says nothing about who runs the site or whether you can trust them. It only shows that whoever controls that domain also controls that key. The padlock tells you your connection to `example.com` is private and hasn't been tampered with. It doesn't tell you that `example.com` is honest.
