internal knowledge

```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Call `clearTimeout` before every new `setTimeout`. Without it, timers pile up and the function fires more than once.

Keep `t` in the closure, not inside the returned function. Otherwise every call gets its own timer and nothing is debounced.

Forward arguments with spread (`...args`), or the called function receives nothing.

Returns nothing. If you need the return value, use a Promise.

Need it to run immediately, then ignore calls for a period? You want throttle, a different function.
