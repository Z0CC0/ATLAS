Internal knowledge.

```js
function debounce(fn, ms) { let t; return (...args) => { clearTimeout(t); t = setTimeout(() => fn(...args), ms); }; }
```

Every call runs `clearTimeout` before the new `setTimeout`. Without it, timers pile up and `fn` fires more than once.

Keep `t` in the closure, not inside the returned function. Otherwise each call gets its own timer and nothing is debounced.

Pass the arguments on with `...args`. Otherwise `fn` receives nothing.

This version returns nothing. If you need the return value, use a Promise.

If you want the function to run immediately and then ignore calls for a period, you need a throttle, which is a different function.
