internal knowledge

Wrap the function in a closure that resets a timer on every call:

```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Why each part matters:

`clearTimeout(t)` has to run before every new `setTimeout`. Without it, timers pile up and `fn` fires more than once.

`t` must live in the closure, not inside the returned function. If it lived inside, every call would get its own timer and nothing would be debounced.

`...args` forwards the arguments. Without the spread, `fn` receives nothing.

This version returns nothing. If you need the return value, use a Promise.

If you want the opposite, where the function runs immediately and then ignores calls for a period, you need a throttle. That's a different function.
