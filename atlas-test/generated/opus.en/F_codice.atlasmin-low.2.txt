Wrap function so each call cancels pending timer and starts new one:

```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Three details make it work:

`clearTimeout` must run before every new `setTimeout`. Otherwise timers pile up and function fires more than once.

`t` must live in closure, not inside returned function. Otherwise every call gets own timer and no debouncing happens.

Arguments must be forwarded with spread (`...args`). Otherwise called function receives nothing.

This version returns nothing. If return value matters, you need Promise.

For opposite case, running immediately then ignoring calls for a period, you want throttle, which is different function.
