`let` allows reassignment; `const` doesn't. Both are block scoped, unlike `var`.

`const` only stops you from reassigning the name. It doesn't freeze the value. An object declared with `const` can still change internally:

```js
const user = { name: "Ada" };
user.name = "Grace";    // works: the object changes
user = { name: "Bob" }; // TypeError: the name can't be reassigned

let count = 1;
count = 2;              // works: let allows reassignment
```
