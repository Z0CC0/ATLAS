internal knowledge (the facts you supplied, used as given and not checked)

**1978, 8086**: 16-bit chip that grew out of the 8080. It was compatible at source level, so 8080 code could be carried over.

**1982, 80286**: added protected mode. Once a program switched into it, the only way back to real mode was a reboot.

**1985, 80386**: moved to 32 bit and added paged virtual memory and virtual 8086 mode.

**1989, 486**: brought the first-level cache and the maths coprocessor onto the chip itself.

**1993, Pentium**: superscalar design with two integer pipelines, able to retire two instructions per cycle.

**1995, Pentium Pro**: introduced out-of-order execution and began translating x86 instructions into internal micro-operations. From this point x86 is an interface rather than the real machine underneath.

**2000, Pentium 4**: chased clock frequency with a very long pipeline and ran into the power wall.

**2003, AMD64**: AMD extended the architecture to 64 bit, and Intel adopted the same instruction set. This was the first time the dominant extension did not come from Intel.

**2006 onward, Core 2**: the direction shifted from raising frequency to adding cores.

**Across generations, vector extensions**: these kept growing, from MMX to SSE, then AVX, then AVX-512.

**Today**: the complexity sits in the layers below the instruction set: branch prediction, the cache hierarchy and speculative execution.

**2018, Spectre and Meltdown**: these attacks showed that speculative execution carried a security cost nobody had priced.
