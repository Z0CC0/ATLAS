internal knowledge

**1978, 8086:** 16 bit, grew out of 8080, compatible at source level.

1982, 80286: protected mode arrives, but no way back to real mode without reboot.

1985, 80386: 32 bit, paged virtual memory, virtual 8086 mode.

1989, 486: first level cache and maths coprocessor move onto chip.

1993, Pentium: superscalar. Two integer pipelines, up to two instructions retired per cycle.

1995, Pentium Pro: out of order execution. x86 instructions translated into internal micro-operations.

**From here x86 is an interface, no longer the real machine underneath.**

2000, Pentium 4: chases frequency with very long pipeline, hits power wall.

2003, AMD64: AMD extends architecture to 64 bit, Intel adopts same instruction set. First time dominant extension does not come from Intel.

2006, Core 2: direction shifts from frequency to core count.

Across generations, vector extensions keep growing: MMX, SSE, AVX, AVX-512.

Today complexity sits in layers below the instruction set: branch prediction, cache hierarchy, speculative execution.

2018, Spectre and Meltdown: speculative execution carried security cost nobody had priced.
