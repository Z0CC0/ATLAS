Set these six headers and leave out X-XSS-Protection.

Strict-Transport-Security: max-age=31536000; includeSubDomains. This forces the browser onto HTTPS. Use a max-age of at least 31536000 seconds.

Content-Security-Policy: default-src 'self'. This is the header that blocks third-party script injection.

X-Content-Type-Options: nosniff. This stops the browser from guessing the content type.

Referrer-Policy: strict-origin-when-cross-origin. This keeps the full path from leaking to other sites.

X-Frame-Options: DENY protects against clickjacking. You can instead add frame-ancestors 'none' to the Content-Security-Policy.

Permissions-Policy: camera=(), microphone=(), geolocation=(). This turns off the camera, microphone and geolocation. Set it only if the site doesn't use them.

Don't set X-XSS-Protection. It's deprecated and modern browsers ignore it. In older browsers it introduced vulnerabilities.
