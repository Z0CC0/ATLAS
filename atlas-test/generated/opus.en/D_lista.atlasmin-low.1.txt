Set these six headers and leave out X-XSS-Protection.

`Strict-Transport-Security: max-age=31536000; includeSubDomains` makes the browser always use HTTPS. Use a max-age of at least 31536000 seconds (one year).

`Content-Security-Policy: default-src 'self'` blocks scripts injected from third parties. To prevent clickjacking, you can add `frame-ancestors 'none'` to this policy.

`X-Frame-Options: DENY` also prevents clickjacking. You can use it instead of the `frame-ancestors` directive.

`X-Content-Type-Options: nosniff` stops the browser from guessing the content type.

`Referrer-Policy: strict-origin-when-cross-origin` keeps the full path from leaking to other sites.

`Permissions-Policy: camera=(), microphone=(), geolocation=()` turns off these features. Use it only if the site doesn't need them.

Don't send **X-XSS-Protection**. It's deprecated, modern browsers ignore it, and it created vulnerabilities in older browsers.
