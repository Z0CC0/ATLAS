```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Call `clearTimeout` before every new `setTimeout`. If you skip it, timers pile up and the function fires more than once.

Declare `t` in the closure, not inside the returned function. Otherwise every call gets its own timer and nothing is debounced.

Pass the arguments through with the spread (`...args`), or `fn` gets no arguments.

This version returns nothing. If you need the return value, use a Promise.

If you want the opposite, running right away and then ignoring calls for a period, you need a throttle. That's a different function.
