```js
function debounce(fn, ms) { let t; return (...args) => { clearTimeout(t); t = setTimeout(() => fn(...args), ms); }; }
```

Call `clearTimeout` before every new `setTimeout`. Without it, timers pile up and `fn` fires more than once.

Keep `t` in the closure, not inside the returned function. Inside it, each call gets its own timer, so nothing gets debounced.

Pass the arguments on with spread (`...args`). Without it, `fn` receives nothing.

This version returns nothing. If you need the return value, use a Promise.

To run immediately and then ignore calls for a period, you want throttle, a different function.
