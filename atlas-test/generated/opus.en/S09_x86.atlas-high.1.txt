**1978:** 8086, 16 bit, grown out of 8080 and compatible with it at source level.

**1982:** 80286 adds protected mode, but no way back to real mode without reboot.

**1985:** 80386 brings 32 bit, paged virtual memory, virtual 8086 mode.

**1989:** 486 pulls first-level cache and maths coprocessor onto chip.

**1993:** Pentium goes superscalar. Two integer pipelines, can retire two instructions per cycle.

**1995:** Pentium Pro adds out-of-order execution and translates x86 instructions into internal micro-operations. From here x86 is an interface, no longer the real machine underneath.

**2000:** Pentium 4 chases frequency with very long pipeline, hits power wall.

**2003:** AMD extends architecture to 64 bit with AMD64. Intel adopts same instruction set. First time dominant extension does not come from Intel.

**2006:** Core 2. Direction shifts from frequency to core count.

**Across generations:** vector extensions grow, MMX, SSE, AVX, AVX-512.

**Today:** complexity sits in layers below: branch prediction, cache hierarchy, speculative execution.

**2018:** Spectre and Meltdown show speculative execution carried security cost nobody had priced.
