For a static site, set these six headers:

- **`Strict-Transport-Security`**: set `max-age` to at least `31536000` seconds and add `includeSubDomains`. The browser then always uses HTTPS.
- **`Content-Security-Policy`**: start with `default-src 'self'`. This blocks script injected from third-party sources.
- **`X-Content-Type-Options: nosniff`**: the browser stops guessing the content type.
- **`Referrer-Policy: strict-origin-when-cross-origin`**: other sites don't see the full path of your pages.
- **Clickjacking protection**: use `X-Frame-Options: DENY`, or put `frame-ancestors 'none'` in the `Content-Security-Policy`.
- **`Permissions-Policy`**: turn off camera, microphone and geolocation if the site doesn't use them.

Leave out **`X-XSS-Protection`**. It is deprecated and modern browsers ignore it. Older browser versions that did use it gained vulnerabilities from it.
