Wrap function in closure that holds one timer, and reset that timer on every call:

```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

`clearTimeout` must run before every new `setTimeout`. Otherwise timers pile up and function fires more than once.

`t` must live in closure, not inside returned function. Otherwise every call gets its own timer and no debouncing happens.

Arguments must be forwarded with spread (`...args`). Otherwise `fn` receives nothing.

This version returns nothing. If return value matters, you need a Promise.

If you want the opposite, running immediately and then ignoring calls for a period, that is a throttle, which is a different function.
