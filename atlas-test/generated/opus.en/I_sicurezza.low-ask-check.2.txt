No. Anything that reaches the browser can be read. Obfuscation falls apart as soon as someone opens the developer tools or looks at the network requests.

Keep the key on the server. Your frontend should call an endpoint on your own backend, and that backend calls the service using the key.

Put a rate limit on that backend endpoint. Without one, anyone can use it to spend your key for free.

If the key has already been published, treat it as compromised and rotate it right away. Removing it from the code is not enough.

Taking it out in a new commit doesn't make it go away. It stays in the repository history, and anyone who already has a clone still has the key.
