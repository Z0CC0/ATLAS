**No.** Anything that reaches the browser can be read. Obfuscation stops working as soon as someone opens the developer tools or looks at the network requests.

Keep the key on your server. The frontend should call an endpoint on your own backend, and that backend calls the service using the key.

That backend endpoint needs a rate limit. Without one, anyone can use it to call the service on your key for free.

If the key has already been published, treat it as compromised and rotate it right away. Removing it from the code is not enough.

Taking it out in a new commit also doesn't help. The key is still in the repository history, and anyone who already has a clone has it.
