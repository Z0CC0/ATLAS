No. Obfuscation doesn't protect it. Anything that reaches the browser can be read, and the obfuscation stops working as soon as someone opens the developer tools or watches the network requests.

Keep the key on your server instead. Have the frontend call an endpoint on your own backend, and have that backend call the service with the key.

Put a rate limit on that backend endpoint. Without one, anyone can use the endpoint to spend your key for free.

If the key has already been published, treat it as compromised and rotate it right away. Removing it from the code isn't enough. Taking it out of a commit also isn't enough, because it stays in the repository history and anyone who already cloned the repository has it.
