internal knowledge

Set six headers and leave out one.

**Strict-Transport-Security**: `max-age` of at least 31536000 seconds, with `includeSubDomains`. This forces the browser onto HTTPS.

**Content-Security-Policy**: `default-src 'self'`. This is what blocks third-party script injection.

X-Content-Type-Options: `nosniff`, so the browser does not guess the content type.

Referrer-Policy: `strict-origin-when-cross-origin`, so the full path does not leak to other sites.

X-Frame-Options: `DENY` protects against clickjacking. You can use `frame-ancestors 'none'` inside the Content-Security-Policy instead.

Permissions-Policy: turn off camera, microphone and geolocation, as long as the site does not use them.

Do not set X-XSS-Protection. It is deprecated, modern browsers ignore it, and older versions introduced vulnerabilities.

```
Strict-Transport-Security: max-age=31536000; includeSubDomains
Content-Security-Policy: default-src 'self'; frame-ancestors 'none'
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
X-Frame-Options: DENY
Permissions-Policy: camera=(), microphone=(), geolocation=()
```
