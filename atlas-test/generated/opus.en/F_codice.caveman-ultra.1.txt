```javascript
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Three details make it work:

- **`clearTimeout(t)` before every new `setTimeout`.** Without it, timers pile up and `fn` fires more than once.
- **`let t` stays in the closure, outside the returned function.** If `t` moves inside, every call gets its own timer and nothing is debounced.
- **`...args` forwards the arguments.** Without the spread, `fn` receives nothing.

This version returns nothing. If you need the return value, wrap the call in a Promise.

To run the function right away and then ignore calls for a set time, use a throttle instead. A throttle is a different function.
