Set these six headers, and leave out X-XSS-Protection.

Strict-Transport-Security with a max-age of at least 31536000 seconds and includeSubDomains. It makes the browser use HTTPS every time.

Content-Security-Policy with default-src 'self'. This header is what blocks third-party script injection.

X-Content-Type-Options set to nosniff. It stops the browser from guessing the content type.

Referrer-Policy set to strict-origin-when-cross-origin. Other sites then don't receive your full URL path.

X-Frame-Options set to DENY protects against clickjacking. You can instead add frame-ancestors 'none' to the Content-Security-Policy.

Permissions-Policy should turn off camera, microphone and geolocation if your site doesn't use them.

Don't set X-XSS-Protection at all. It's deprecated, modern browsers ignore it, and older browser versions that honored it introduced vulnerabilities.

Example:

```
Strict-Transport-Security: max-age=31536000; includeSubDomains
Content-Security-Policy: default-src 'self'; frame-ancestors 'none'
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
X-Frame-Options: DENY
Permissions-Policy: camera=(), microphone=(), geolocation=()
```
