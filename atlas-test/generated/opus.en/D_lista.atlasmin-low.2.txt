Set these six headers, and leave out X-XSS-Protection.

**Strict-Transport-Security**: use a max-age of at least 31536000 seconds and add includeSubDomains. This makes the browser always use HTTPS.

**Content-Security-Policy**: use default-src 'self'. This is the header that blocks third-party scripts from being injected into your pages.

**X-Content-Type-Options**: set it to nosniff so the browser doesn't guess the content type.

**Referrer-Policy**: set it to strict-origin-when-cross-origin so other sites don't see the full path of your pages.

**X-Frame-Options**: set it to DENY to protect against clickjacking. You can instead add frame-ancestors 'none' to the Content-Security-Policy.

**Permissions-Policy**: turn off camera, microphone and geolocation if the site doesn't use them.

```
Strict-Transport-Security: max-age=31536000; includeSubDomains
Content-Security-Policy: default-src 'self'; frame-ancestors 'none'
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
X-Frame-Options: DENY
Permissions-Policy: camera=(), microphone=(), geolocation=()
```

Don't set **X-XSS-Protection**. It's deprecated, modern browsers ignore it, and in older browsers it created security holes.
