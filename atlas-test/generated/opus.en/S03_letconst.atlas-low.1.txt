`let` allows reassignment; `const` doesn't let you reassign the name.

With `const`, only the binding stays fixed, not the value. An object declared with `const` can still change internally:

```js
const user = { name: "Ann" };
user.name = "Bob";   // fine: object changed internally
user = {};           // TypeError: name cannot be reassigned

let count = 1;
count = 2;           // fine with let
```

Both are block scoped, unlike `var`, so a variable declared inside `{ }` stays inside that block.
