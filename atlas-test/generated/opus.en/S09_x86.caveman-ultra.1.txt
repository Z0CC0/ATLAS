## Evolution of x86

**Starting point: the 8086 (1978).** The 8086 is a 16-bit chip that grows out of the 8080. It is compatible with the 8080 at source level, not binary level. That choice starts a pattern that lasts the whole history: each new chip carries the old software forward.

**Protected mode arrives: the 80286 (1982).** The 80286 introduces protected mode. It has one flaw: once in protected mode, the only way back to real mode is a reboot. Old real-mode software and the new mode do not mix well.

**Modern base: the 80386 (1985).** The 80386 fixes the 80286's problem and sets the base for decades:
- 32-bit.
- Paged virtual memory.
- Virtual 8086 mode, which runs old real-mode programs inside protected mode with no reboot.

**Integration: the 486 (1989).** The 486 moves the first-level cache and the maths coprocessor onto the chip. Before this, both sat outside the processor.

**Parallelism inside the core: the Pentium (1993).** The Pentium is superscalar. Two integer pipelines can retire two instructions per cycle.

**Turning point: the Pentium Pro (1995).** The Pentium Pro introduces out-of-order execution. It also translates x86 instructions into internal micro-operations. From this chip on, x86 is an interface, not the real machine underneath. The instruction set stays for compatibility, and the hardware underneath is free to change.

**Frequency dead end: the Pentium 4 (2000).** The Pentium 4 chases clock frequency with a very long pipeline. It hits the power wall.

**64-bit from outside Intel: AMD64 (2003).** AMD extends the architecture to 64-bit with AMD64. Intel adopts the same instruction set. For the first time, the dominant x86 extension does not come from Intel.

**From frequency to cores: the Core 2 (2006).** After the power wall, the direction shifts from higher frequency to more cores, starting with the Core 2.

**Vector extensions: a parallel thread.** The vector extensions grow across generations, from MMX to SSE, then AVX, then AVX-512.

**Today.** The complexity now sits in the layers below the instruction set:
- branch prediction
- the cache hierarchy
- speculative execution

**The cost: Spectre and Meltdown (2018).** In 2018, Spectre and Meltdown show that speculative execution carried a security cost nobody had priced. This goes back to the Pentium Pro decision. Hiding the real machine behind the x86 interface made processors fast, and the hidden machinery also leaked data.
