Wrap the function in a closure that holds one timer. Each call cancels the pending timer and starts a new one:

```js
function debounce(fn, ms) { let t; return (...args) => { clearTimeout(t); t = setTimeout(() => fn(...args), ms); }; }
```

Three details make it work:

- **`clearTimeout(t)` before every new `setTimeout`.** If you skip it, timers pile up and `fn` fires more than once.
- **`t` lives in the closure, not inside the returned function.** If it lived inside, every call would get its own timer and nothing would be debounced.
- **`...args` forwards the arguments.** Without the spread, `fn` receives nothing.

**Limit:** this version returns nothing. If you need `fn`'s return value, you need a Promise.

**Opposite case:** to run `fn` immediately and then ignore calls for a period, use a throttle instead. That is a different function.
