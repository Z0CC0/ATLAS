Set these six headers. Leave out X-XSS-Protection.

Strict-Transport-Security: use a max-age of at least 31536000 seconds and add includeSubDomains. This forces the browser onto HTTPS.

Content-Security-Policy: set default-src 'self'. This is the header that blocks third-party script injection.

X-Content-Type-Options: set it to nosniff, so the browser doesn't guess the content type.

Referrer-Policy: set it to strict-origin-when-cross-origin, so the full path doesn't leak to other sites.

X-Frame-Options: set it to DENY to stop clickjacking. You can instead put frame-ancestors 'none' inside the Content-Security-Policy.

Permissions-Policy: switch off camera, microphone and geolocation if the site doesn't use them.

```
Strict-Transport-Security: max-age=31536000; includeSubDomains
Content-Security-Policy: default-src 'self'; frame-ancestors 'none'
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
X-Frame-Options: DENY
Permissions-Policy: camera=(), microphone=(), geolocation=()
```

**Don't send X-XSS-Protection.** It's deprecated. Modern browsers ignore it, and in older browsers it introduced vulnerabilities.
