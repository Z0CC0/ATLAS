Set these six headers, and leave out a seventh:

Strict-Transport-Security with `max-age` of at least 31536000 seconds and `includeSubDomains`. It forces the browser onto HTTPS.

Content-Security-Policy with `default-src 'self'`. This is the header that blocks third-party script injection.

X-Content-Type-Options set to `nosniff`, so the browser doesn't guess the content type.

Referrer-Policy set to `strict-origin-when-cross-origin`, so the full path doesn't leak to other sites.

X-Frame-Options set to `DENY`, or `frame-ancestors 'none'` inside the Content-Security-Policy. Either one protects against clickjacking.

Permissions-Policy to turn off camera, microphone and geolocation if the site doesn't use them.

Don't set X-XSS-Protection. It's deprecated, modern browsers ignore it, and older browser versions that used it introduced vulnerabilities.

```
Strict-Transport-Security: max-age=31536000; includeSubDomains
Content-Security-Policy: default-src 'self'; frame-ancestors 'none'
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
X-Frame-Options: DENY
Permissions-Policy: camera=(), microphone=(), geolocation=()
```
