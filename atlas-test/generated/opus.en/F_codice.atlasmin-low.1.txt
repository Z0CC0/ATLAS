Wrap function in closure that holds one timer and resets it on every call:

```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Usage:

```js
const onResize = debounce(() => console.log('resized'), 200);
window.addEventListener('resize', onResize);
```

How it works:

`clearTimeout(t)` must run before every new `setTimeout`. Without it, timers pile up and function fires more than once.

`t` must live in closure, not inside returned function. Otherwise every call gets its own timer and no debouncing happens.

`...args` forwards arguments. Without spread, called function receives nothing.

This version returns nothing. If return value matters, you need a Promise.

Need opposite behavior, running immediately and then ignoring calls for a period? That's a throttle, a different function.
