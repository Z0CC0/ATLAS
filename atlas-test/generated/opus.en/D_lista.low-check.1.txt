internal knowledge

Set these six headers, and leave out X-XSS-Protection.

**Strict-Transport-Security**: `max-age=31536000; includeSubDomains` (max-age of at least 31536000 seconds). It forces the browser onto HTTPS.

**Content-Security-Policy**: `default-src 'self'`. This is the header that blocks third-party script injection. If you add `frame-ancestors 'none'` here, it also protects against clickjacking.

X-Content-Type-Options: `nosniff`, so the browser does not guess the content type.

Referrer-Policy: `strict-origin-when-cross-origin`, so other sites never see your full URL path.

X-Frame-Options: `DENY`, against clickjacking. You only need it if you are not already using `frame-ancestors 'none'` in the CSP.

Permissions-Policy: if the site does not use camera, microphone or geolocation, turn them off, for example `camera=(), microphone=(), geolocation=()`.

Do not send X-XSS-Protection. It is deprecated, modern browsers ignore it, and in older browsers it introduced vulnerabilities.
