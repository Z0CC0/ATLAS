```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

You must call `clearTimeout` before each new `setTimeout`. Otherwise the timers pile up and `fn` fires more than once.

`t` has to live in the closure, not inside the returned function. Otherwise every call gets its own timer and nothing is debounced.

Pass the arguments on with the spread (`...args`), or `fn` receives nothing.

This version returns nothing. If you need the return value, use a Promise.

If you want the opposite, running right away and then ignoring calls for a while, you need a throttle, which is a different function.
