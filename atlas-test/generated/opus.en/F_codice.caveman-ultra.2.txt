```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Here is how it works:

- **`clearTimeout(t)` runs before each new `setTimeout`.** Each call cancels the pending timer. Without that, timers pile up and `fn` fires more than once.
- **`t` lives in the closure, outside the returned function.** All calls share one timer. If you move `t` inside the returned function, each call gets its own timer and nothing is debounced.
- **`...args` passes the arguments on.** Without the spread, `fn` gets called with no arguments.

Two limits:

- **It returns nothing.** If you need `fn`'s return value, wrap the call in a Promise.
- **It only runs after the calls stop.** If you want `fn` to run right away and then ignore calls for a period, use a throttle. A throttle is a different function.
