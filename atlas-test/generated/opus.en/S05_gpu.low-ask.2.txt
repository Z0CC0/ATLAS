Biggest difference is frame generation, not raw performance: on traditional rasterisation the 5080 is only about 10-15 per cent faster than the 4080.

Underneath, the 5080 moves to the Blackwell architecture, replacing Ada Lovelace. It swaps GDDR6X memory for GDDR7, which raises memory bandwidth from about 717 to about 960 gigabytes per second.

It also draws more power: rated draw goes from 320 to 360 watts. The power connector stays the same 16-pin type, so cabling doesn't change.

If you already own a 4080 and mostly play without frame generation, the jump is modest. The 5080 makes more sense if you'll use frame generation, or if you're buying new.
