For a static site, set these six headers:

- **`Strict-Transport-Security: max-age=31536000; includeSubDomains`** forces the browser onto HTTPS. Use a max-age of at least 31536000 seconds (one year).
- **`Content-Security-Policy: default-src 'self'`** blocks third-party script injection.
- **`X-Content-Type-Options: nosniff`** stops the browser from guessing the content type.
- **`Referrer-Policy: strict-origin-when-cross-origin`** keeps the full path from leaking to other sites.
- **`X-Frame-Options: DENY`** protects against clickjacking. You can use `frame-ancestors 'none'` inside your Content-Security-Policy instead.
- **`Permissions-Policy: camera=(), microphone=(), geolocation=()`** turns off these features. Use it if the site does not need them.

Do not set **`X-XSS-Protection`**. It is deprecated, and modern browsers ignore it. In older browsers, it introduced vulnerabilities.

Here is the full set, with the clickjacking protection inside the CSP:

```
Strict-Transport-Security: max-age=31536000; includeSubDomains
Content-Security-Policy: default-src 'self'; frame-ancestors 'none'
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
Permissions-Policy: camera=(), microphone=(), geolocation=()
```
