Wrap the function in a closure that holds one timer. Each call cancels the pending timer and starts a new one:

```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Usage:

```js
const onResize = debounce(() => console.log('resized'), 200);
window.addEventListener('resize', onResize);
```

Why each part matters:

- **`clearTimeout(t)` before every new `setTimeout`.** Without it, timers pile up and `fn` fires more than once.
- **`let t` lives in the closure, outside the returned function.** If `t` were declared inside the returned function, every call would get its own timer, and no debouncing would happen.
- **`...args` forwarded with the spread.** Without it, `fn` receives nothing.

**Limitation:** this version returns nothing. If you need `fn`'s return value, the debounced function has to return a Promise.

Want `fn` to run right away and then ignore calls for a period? That is a throttle, which is a different function.
