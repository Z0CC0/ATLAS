```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

What to get right:

- **`clearTimeout(t)` before every new `setTimeout`.** If you skip it, timers pile up and `fn` fires more than once.
- **`let t` goes in the closure, outside the returned function.** If you move it inside, every call gets its own timer and nothing is debounced.
- **Pass the arguments through with `...args`.** Without the spread, `fn` gets no arguments.
- **It returns nothing.** If you need `fn`'s return value, wrap it in a Promise.

If you want the opposite, running right away and then ignoring calls for a while, you need a throttle. That's a different function.
