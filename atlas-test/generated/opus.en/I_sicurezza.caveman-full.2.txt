**No.** Anything that reaches the browser is readable. Obfuscation fails as soon as someone opens developer tools or looks at network requests.

**Do this instead:**
- Keep the key on your server.
- Have the frontend call an endpoint on your own backend. The backend then calls the service with the key.
- Put a rate limit on that backend endpoint. If you skip it, anyone can use the endpoint to spend your key for free.

**If the key has already been published:**
- Treat it as compromised and rotate it now. Removing it from the code does not fix this.
- Taking it out with a new commit is not enough. The key stays in the repository history, and anyone who already cloned the repository has it.
