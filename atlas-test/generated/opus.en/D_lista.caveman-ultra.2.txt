Set these six headers. Omit one.

- **`Strict-Transport-Security: max-age=31536000; includeSubDomains`**: forces browser onto HTTPS. Use max-age 31536000 seconds or higher.
- **`Content-Security-Policy: default-src 'self'`**: blocks third-party script injection.
- **`X-Content-Type-Options: nosniff`**: stops browser from guessing content type.
- **`Referrer-Policy: strict-origin-when-cross-origin`**: full path does not leak to other sites.
- **`X-Frame-Options: DENY`**: stops clickjacking. Or add `frame-ancestors 'none'` inside Content-Security-Policy instead.
- **`Permissions-Policy: camera=(), microphone=(), geolocation=()`**: turns off camera, microphone and geolocation. Use only if site not need them.

Omit **`X-XSS-Protection`**. Deprecated. Modern browsers ignore it, older versions introduced vulnerabilities.

Example:
```
Strict-Transport-Security: max-age=31536000; includeSubDomains
Content-Security-Policy: default-src 'self'; frame-ancestors 'none'
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
X-Frame-Options: DENY
Permissions-Policy: camera=(), microphone=(), geolocation=()
```
