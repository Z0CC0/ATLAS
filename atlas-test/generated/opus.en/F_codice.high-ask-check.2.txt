```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Use: `const onResize = debounce(() => console.log('resized'), 200);`

`clearTimeout` must run before every new `setTimeout`. Otherwise timers pile up, function fires more than once.

`t` must live in closure, not inside returned function. Otherwise every call gets own timer, no debouncing.

Forward arguments with spread (`...args`). Otherwise `fn` receives nothing.

Returns nothing. Return value matters: need Promise.

Run immediately, then ignore for a period: that's throttle, different function.
