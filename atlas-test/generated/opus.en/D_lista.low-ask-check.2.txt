internal knowledge

For a static site, set six headers and leave out a seventh:

Strict-Transport-Security, with a max-age of at least 31536000 seconds and includeSubDomains, so the browser always uses HTTPS.

Content-Security-Policy with default-src 'self'. This blocks script injection from third parties.

X-Content-Type-Options: nosniff, so the browser does not guess the content type.

Referrer-Policy: strict-origin-when-cross-origin, so other sites don't see your full URL path.

X-Frame-Options: DENY to protect against clickjacking. You can use frame-ancestors 'none' inside the Content-Security-Policy instead.

Permissions-Policy to turn off camera, microphone and geolocation if the site doesn't use them.

Do not send X-XSS-Protection. It is deprecated, and modern browsers ignore it. Older browsers that did support it could be made vulnerable by it.

```
Strict-Transport-Security: max-age=31536000; includeSubDomains
Content-Security-Policy: default-src 'self'; frame-ancestors 'none'
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
X-Frame-Options: DENY
Permissions-Policy: camera=(), microphone=(), geolocation=()
```
