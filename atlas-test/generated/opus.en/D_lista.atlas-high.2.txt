For a static site, set these six headers:

**Strict-Transport-Security**: `max-age=31536000; includeSubDomains`. This forces the browser onto HTTPS. Use a max-age of at least 31536000 seconds.

**Content-Security-Policy**: `default-src 'self'`. This is the header that blocks third-party script injection. You can also add `frame-ancestors 'none'` here to protect against clickjacking.

**X-Content-Type-Options**: `nosniff`. This stops the browser from guessing the content type.

**Referrer-Policy**: `strict-origin-when-cross-origin`. Other sites won't see the full path of your pages.

**X-Frame-Options**: `DENY`. This protects against clickjacking. You don't need it if your Content-Security-Policy already includes `frame-ancestors 'none'`.

**Permissions-Policy**: turn off camera, microphone and geolocation if the site doesn't use them, for example `camera=(), microphone=(), geolocation=()`.

Don't set X-XSS-Protection. It's deprecated, modern browsers ignore it, and older versions introduced vulnerabilities.
