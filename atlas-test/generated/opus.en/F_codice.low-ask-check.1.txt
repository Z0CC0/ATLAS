internal knowledge

```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Each call cancels the pending timer and starts a new one, so `fn` runs only once the calls stop for `ms` milliseconds.

`clearTimeout` has to run before every new `setTimeout`. Otherwise timers pile up and `fn` fires more than once.

`t` has to live in the closure, not inside the returned function. Otherwise every call gets its own timer and nothing gets debounced.

`...args` forwards the arguments. Without it, `fn` receives nothing.

This version returns nothing. If you need `fn`'s return value, use a Promise.

If you want the opposite, running right away and then ignoring calls for a while, you need a throttle. That's a different function.
