For a static site, set these six headers and skip a seventh:

- **`Strict-Transport-Security: max-age=31536000; includeSubDomains`** forces the browser onto HTTPS. Use a max-age of at least 31536000 seconds (one year).
- **`Content-Security-Policy: default-src 'self'`** blocks third-party script injection. Add `frame-ancestors 'none'` to it if you want CSP to handle clickjacking too.
- **`X-Content-Type-Options: nosniff`** stops the browser from guessing the content type.
- **`Referrer-Policy: strict-origin-when-cross-origin`** keeps the full path from leaking to other sites.
- **`X-Frame-Options: DENY`** protects against clickjacking. You can use `frame-ancestors 'none'` in the CSP instead.
- **`Permissions-Policy: camera=(), microphone=(), geolocation=()`** switches off camera, microphone and geolocation. Only do this if the site doesn't use them.

Leave out **`X-XSS-Protection`**. It's deprecated: modern browsers ignore it, and older versions introduced vulnerabilities.

Full set:

```
Strict-Transport-Security: max-age=31536000; includeSubDomains
Content-Security-Policy: default-src 'self'; frame-ancestors 'none'
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
X-Frame-Options: DENY
Permissions-Policy: camera=(), microphone=(), geolocation=()
```
