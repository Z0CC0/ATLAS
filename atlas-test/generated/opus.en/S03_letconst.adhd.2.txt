**Use `const` when the name should always point to the same value. Use `let` when you need to reassign it.**

- **`let` allows reassignment.** You can point the name at a new value later.
- **`const` prevents reassigning the name.** It does not stop you from modifying the value itself.
- **So a `const` object can still change internally.** You can add, remove or update its properties. You just can't assign a different object to that name.
- **Both are block scoped, unlike `var`.** A `let` or `const` declared inside `{ }` exists only inside that block.

```js
let count = 1;
count = 2;            // fine: let allows reassignment

const user = { name: "Ana" };
user.name = "Bo";     // fine: the object changes internally
user = {};            // TypeError: the name can't be reassigned

if (true) {
  let a = 1;
  const b = 2;
}
// a and b don't exist out here (block scoped)
```

Next: start with `const` by default, and switch a declaration to `let` only when you actually need to reassign it.
