No. Anything that reaches the browser can be read by whoever is using it. Obfuscation stops working as soon as someone opens the developer tools or looks at the network requests, because the key shows up there in plain text.

Keep the key on the server. Your frontend should call an endpoint on your own backend, and that backend calls the service using the key.

Put a rate limit on that backend endpoint. Without one, anyone can use your endpoint as a free way to use your key.

If the key has already been published, treat it as compromised and rotate it right away. Removing it from the code is not enough.

Deleting it in a new commit doesn't help either. The key is still in the repository history, and anyone who already has a clone already has the key.
