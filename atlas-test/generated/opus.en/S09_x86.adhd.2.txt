# How x86 evolved, from 1978 to today

The short version: x86 started as a real chip design. Over time it became a compatibility interface, a contract that the actual hardware underneath translates and works around. The rest of this traces how that happened.

## 1. Foundations: 16 bits and source compatibility (1978)

- **8086 (1978):** a 16-bit processor that grew out of the earlier 8080.
- It was compatible with the 8080 at the **source level**, not the binary level. Code had to be reassembled, but it didn't have to be rewritten.
- This sets the pattern for everything that follows: each new chip has to keep old software working.

## 2. The 1980s: protection, 32 bits and virtual memory

- **80286 (1982):** added **protected mode**, which lets the hardware stop programs from interfering with each other.
  - The catch: once the chip entered protected mode, the only way back to the old real mode was a reboot.
- **80386 (1985):** the big step of the decade. It added three things:
  1. **32-bit** operation
  2. **Paged virtual memory**
  3. **Virtual 8086 mode**, which runs old real-mode software safely inside the protected environment. This fixed the 286's one-way-door problem.

## 3. Pulling more onto the chip (1989–1993)

- **486 (1989):** moved two parts that used to sit outside the processor onto the chip itself:
  - the **level 1 cache**
  - the **maths coprocessor**
- **Pentium (1993):** **superscalar**. It had two integer pipelines, so it could retire two instructions in one cycle instead of one.

## 4. The turning point: x86 becomes an interface (1995)

- **Pentium Pro (1995):** made two changes that redefine the architecture:
  1. **Out-of-order execution:** the chip runs instructions in whatever order keeps its units busy, not strictly in program order.
  2. **Translation into micro-operations:** x86 instructions get broken into simpler internal operations, and those are what actually execute.
- **Why this matters:** from here on, x86 is the language software speaks, not the machine that runs it. The real machine underneath is something else, and it is free to change from one generation to the next.

## 5. The frequency race and the power wall (2000)

- **Pentium 4 (2000):** chased higher clock frequency by using a **very long pipeline**.
- It ran into the **power wall**: pushing frequency further cost too much power to keep going.
- This dead end sets up the next big change in direction.

## 6. 64 bits, and it came from AMD (2003)

- **AMD64 (2003):** AMD extended the architecture to **64 bits**.
- Intel then adopted **the same instruction set**.
- This was the first time the dominant extension to x86 didn't come from Intel.

## 7. From faster cores to more cores (2006 onward)

- **Core 2 (2006):** the industry stopped chasing frequency and started adding **cores**.
- After the power wall, more performance meant doing more work in parallel, not running one stream faster.

## 8. Vector extensions grow alongside (across generations)

The instruction set has kept adding wider vector capabilities, which run the same operation on many pieces of data at once:

**MMX → SSE → AVX → AVX-512**

## 9. Today: the complexity sits below the interface

Most of the engineering now happens in layers that software never addresses directly:
- **branch prediction**
- **the cache hierarchy**
- **speculative execution**

## 10. The bill arrives: Spectre and Meltdown (2018)

- **Spectre and Meltdown (2018)** showed that speculative execution carried a **security cost nobody had priced in**.
- This ties back to section 4. Once x86 became an interface over a hidden machine, the hidden machine's tricks for speed could leak information. The abstraction had a gap in it.

## The through-line

| Era | Main push |
|---|---|
| 1978–1985 | Modes and width: 16 bit → protected mode → 32 bit + virtual memory |
| 1989–1993 | Integration and parallel pipelines |
| 1995 | x86 becomes a translated interface |
| 2000–2006 | Frequency hits the wall; the shift to cores |
| 2003 | 64 bit, led by AMD |
| Today | Complexity below the interface, and its security cost |
