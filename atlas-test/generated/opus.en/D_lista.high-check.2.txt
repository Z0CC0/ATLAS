internal knowledge

Set these six headers, and drop X-XSS-Protection:

**Strict-Transport-Security**: `max-age=31536000; includeSubDomains`. This makes the browser always use HTTPS. Use a max-age of at least 31536000 seconds (one year).

**Content-Security-Policy**: `default-src 'self'`. This blocks scripts injected from third-party sources.

**X-Content-Type-Options**: `nosniff`. This stops the browser from guessing the content type.

**Referrer-Policy**: `strict-origin-when-cross-origin`. Other sites see only your origin, not the full path.

**X-Frame-Options**: `DENY`. This protects against clickjacking. You can instead add `frame-ancestors 'none'` to the Content-Security-Policy.

**Permissions-Policy**: turn off camera, microphone and geolocation if the site doesn't use them, for example `camera=(), microphone=(), geolocation=()`.

Don't set **X-XSS-Protection**. It's deprecated: modern browsers ignore it, and older browsers that supported it had vulnerabilities caused by it.

```
Strict-Transport-Security: max-age=31536000; includeSubDomains
Content-Security-Policy: default-src 'self'; frame-ancestors 'none'
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
X-Frame-Options: DENY
Permissions-Policy: camera=(), microphone=(), geolocation=()
```
