**x86, 1978 to today**

**16-bit start**
- **8086 (1978)**: 16 bit. Grew out of 8080, source-level compatible. That compatibility constraint shapes every step after.
- **80286 (1982)**: protected mode. Catch: no way back to real mode without reboot.

**32-bit foundation**
- **80386 (1985)**: 32 bit, paged virtual memory, virtual 8086 mode. Old real-mode code now runs inside protected mode. Fixes 286's one-way trap.
- **486 (1989)**: first-level cache and maths coprocessor moved onto the chip.

**Parallelism inside one core**
- **Pentium (1993)**: superscalar. Two integer pipelines, up to two instructions retired per cycle.
- **Pentium Pro (1995)**: out-of-order execution. x86 instructions translated into internal micro-operations. Turning point: from here x86 is an interface, no longer the real machine underneath.

**Frequency race and its end**
- **Pentium 4 (2000)**: very long pipeline to chase clock frequency. Hits the power wall.

**64-bit, from outside Intel**
- **AMD64 (2003)**: AMD extends the architecture to 64 bit. Intel adopts the same instruction set. First time the dominant extension does not come from Intel.

**Cores instead of clocks**
- **Core 2 (2006)**: direction shifts from frequency to core count.

**Vectors, growing in parallel**
- Across generations: MMX, then SSE, then AVX, then AVX-512. Each one widens data-parallel work per instruction.

**Today**
- Complexity now sits in the layers below the ISA: branch prediction, cache hierarchy, speculative execution.
- **Spectre and Meltdown (2018)**: showed speculative execution carried a security cost nobody had priced.

The pattern: the ISA stays compatible on the surface. Underneath, the machine kept getting rebuilt, first for frequency, then for core count, and now with speculation, which turned out to be risky.
