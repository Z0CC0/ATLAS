internal knowledge

Set these six:

**Strict-Transport-Security**: `max-age` of at least 31536000 seconds plus `includeSubDomains`, so browsers always use HTTPS.

**Content-Security-Policy**: `default-src 'self'`. This is the header that blocks script injected from third parties.

**X-Content-Type-Options**: `nosniff`, so the browser doesn't guess the content type.

**Referrer-Policy**: `strict-origin-when-cross-origin`, so other sites don't receive the full path.

**X-Frame-Options**: `DENY`, or `frame-ancestors 'none'` inside the Content-Security-Policy, to stop clickjacking.

**Permissions-Policy**: turn off camera, microphone and geolocation if the site doesn't use them.

Don't set **X-XSS-Protection**. It's deprecated: modern browsers ignore it, and older browsers had vulnerabilities caused by it.
