internal knowledge

Set these six headers on a static site:

`Strict-Transport-Security: max-age=31536000; includeSubDomains` makes the browser use HTTPS. Use a max-age of at least 31536000 seconds.

`Content-Security-Policy: default-src 'self'` blocks injected third-party scripts.

`X-Content-Type-Options: nosniff` stops the browser from guessing the content type.

`Referrer-Policy: strict-origin-when-cross-origin` keeps your full URL path from leaking to other sites.

`X-Frame-Options: DENY` protects against clickjacking. You can get the same result by adding `frame-ancestors 'none'` to the Content-Security-Policy.

`Permissions-Policy: camera=(), microphone=(), geolocation=()` turns off the camera, microphone and geolocation. Only use it if the site doesn't need them.

**Don't set `X-XSS-Protection`.** It's deprecated. Modern browsers ignore it, and older browsers that support it introduced vulnerabilities.
