These six headers cover a static site, and X-XSS-Protection should be left out.

Strict-Transport-Security: `max-age=31536000; includeSubDomains`. This forces the browser onto HTTPS. Use a max-age of at least 31536000 seconds.

Content-Security-Policy: `default-src 'self'`. This is the header that blocks third-party script injection. You can also add `frame-ancestors 'none'` to it to protect against clickjacking.

X-Content-Type-Options: `nosniff`. This stops the browser from guessing the content type.

Referrer-Policy: `strict-origin-when-cross-origin`. This keeps the full path from leaking to other sites.

X-Frame-Options: `DENY`. This also protects against clickjacking. It isn't needed if you already set `frame-ancestors 'none'` in the CSP.

Permissions-Policy: `camera=(), microphone=(), geolocation=()`. This turns off those features, which makes sense only if the site doesn't use them.

**Don't set X-XSS-Protection.** It's deprecated, modern browsers ignore it, and older versions of it introduced vulnerabilities.
