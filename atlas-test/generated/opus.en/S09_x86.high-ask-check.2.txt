internal knowledge

x86 went from a 16-bit chip to an interface sitting over a very different machine, keeping compatibility the whole way.

8086 (1978): 16 bit, grew out of the 8080, compatible at source level.

80286 (1982): introduced protected mode, but no way back to real mode without a reboot.

80386 (1985): 32 bit, paged virtual memory and virtual 8086 mode.

486 (1989): first-level cache and maths coprocessor pulled onto the chip.

Pentium (1993): superscalar, with two integer pipelines that can retire two instructions per cycle.

Pentium Pro (1995): out-of-order execution. It translates x86 instructions into internal micro-operations. **From here x86 is an interface, no longer the real machine underneath.**

Pentium 4 (2000): chased frequency with a very long pipeline and hit the power wall.

AMD64 (2003): AMD extended the architecture to 64 bit, and Intel adopted the same instruction set. First time the dominant extension did not come from Intel.

Core 2 (2006): direction shifted from frequency to core count.

Vector extensions grew across generations: MMX, SSE, AVX, AVX-512.

Today most of the complexity sits in the layers below: branch prediction, cache hierarchy, speculative execution.

Spectre and Meltdown (2018): showed speculative execution carried a security cost nobody had priced.
