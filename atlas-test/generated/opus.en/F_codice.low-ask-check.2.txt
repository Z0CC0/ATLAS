internal knowledge

Wrap the function in a closure that holds a timer, and reset that timer on every call:

```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Three details make it work:

`clearTimeout(t)` runs before every new `setTimeout`. Without it, timers pile up and `fn` fires more than once.

`t` lives in the closure, outside the returned function. If you declare it inside, each call gets its own timer and nothing gets debounced.

`...args` passes the arguments through to `fn`. Without the spread, `fn` receives nothing.

**Limitation:** this version returns nothing. If you need the return value of `fn`, you have to return a Promise instead.

If you want the opposite behaviour, where the function runs right away and further calls are ignored for a period, you need a throttle. That's a different function.
