internal knowledge

`let` lets you reassign a variable. `const` doesn't let you reassign the name, but you can still change the value it holds. For example, an object declared with `const` can still change internally. Both are block scoped, unlike `var`.

```js
let count = 1;
count = 2;          // works

const user = { name: "Ana" };
user.name = "Bea";  // works: the object changes internally
user = {};          // TypeError: the name can't be reassigned
```
