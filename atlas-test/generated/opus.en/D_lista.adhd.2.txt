Add these response headers to every page:

```
Strict-Transport-Security: max-age=31536000; includeSubDomains
Content-Security-Policy: default-src 'self'; frame-ancestors 'none'
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
X-Frame-Options: DENY
Permissions-Policy: camera=(), microphone=(), geolocation=()
```

## What each one does

**Core protection**
1. **Strict-Transport-Security** makes the browser use HTTPS only. Set `max-age` to at least 31536000 seconds (1 year) and include `includeSubDomains`.
2. **Content-Security-Policy** with `default-src 'self'` blocks scripts injected from third-party sources.
3. **X-Content-Type-Options: nosniff** stops the browser from guessing a file's content type.

**Leaks and embedding**
1. **Referrer-Policy: strict-origin-when-cross-origin** stops your full URL path from being sent to other sites.
2. **Clickjacking:** you need only one of these two. Use `frame-ancestors 'none'` inside the CSP or `X-Frame-Options: DENY`. The block above sets both, which is also fine.
3. **Permissions-Policy** turns off camera, microphone and geolocation. Leave a feature out of the list if your site actually uses it.

## Leave this one out

**X-XSS-Protection** is deprecated, so don't set it. Modern browsers ignore it, and in older browsers it created vulnerabilities.

Next: paste the block into your server or host's header config, then open your site in browser DevTools → Network → click the page → check that the response headers include all six (about 10 minutes).
