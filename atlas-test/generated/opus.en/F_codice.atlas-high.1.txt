Wrap the function in a closure that holds one timer and resets it on every call:

```js
function debounce(fn, ms) { let t; return (...args) => { clearTimeout(t); t = setTimeout(() => fn(...args), ms); }; }
```

`clearTimeout` has to run before every new `setTimeout`. Otherwise timers pile up and `fn` fires more than once.

`t` has to live in the closure, not inside the returned function. Otherwise each call gets its own timer and nothing is debounced.

The arguments are passed on with the spread `...args`. Without it, `fn` gets nothing.

This version returns nothing. If you need the return value, use a Promise.

If you want the opposite, running right away and then ignoring calls for a while, that's a throttle, which is a different function.
