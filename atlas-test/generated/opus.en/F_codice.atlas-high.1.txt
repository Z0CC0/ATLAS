Closure holding one timer, reset on every call:

```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

**`clearTimeout(t)` before every new `setTimeout`.** Without it, timers pile up and `fn` fires more than once.

`t` lives in closure, not inside returned function. Otherwise each call gets its own timer and nothing is debounced.

Arguments forwarded with spread (`...args`). Otherwise `fn` receives nothing.

Returns nothing. If you need the return value, use a Promise.

Want to run immediately, then ignore calls for a period? That's throttle, a different function.
