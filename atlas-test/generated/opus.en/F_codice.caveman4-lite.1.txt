Use a closure that holds one timer, and reset that timer on every call:

```js
function debounce(fn, ms) { let t; return (...args) => { clearTimeout(t); t = setTimeout(() => fn(...args), ms); }; }
```

Why each part matters:

- **`clearTimeout(t)` before each new `setTimeout`:** without it, timers pile up and `fn` fires more than once.
- **`let t` in the outer closure:** it must sit outside the returned function. Inside, every call would get its own timer, and nothing would be debounced.
- **`...args` spread:** this passes the arguments on to `fn`. Without it, `fn` receives nothing.

This version returns nothing. If you need `fn`'s return value, wrap the result in a Promise.

If you want the opposite behavior, where the function runs right away and then ignores calls for a period, you need a throttle. That's a different function.
