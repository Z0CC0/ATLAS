The RTX 5080 is a newer generation than the RTX 4080. The 5080 uses the Blackwell architecture, and the 4080 uses Ada Lovelace.

**Memory:** The 5080 uses GDDR7 memory instead of the 4080's GDDR6X. Memory bandwidth goes up from about 717 GB/s to about 960 GB/s.

**Performance:** The biggest improvement is in frame generation, not raw rasterisation. In games without frame generation, expect the 5080 to be about 10–15% faster than the 4080.

**Power:** Rated power draw goes up from 320 W to 360 W. Both cards use the same 16-pin power connector.

**In short:** If you already have a 4080, the upgrade is mainly worth it if you use frame generation. For raw rasterisation alone, the gain is modest. If you are choosing between the two new, the 5080 gives you more memory bandwidth and better frame generation. In return, it draws a little more power.
