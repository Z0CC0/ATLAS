Set six headers. Skip one.

**Set:**

- `Strict-Transport-Security: max-age=31536000; includeSubDomains` forces browser onto HTTPS. Use max-age of 31536000 seconds or more.
- `Content-Security-Policy: default-src 'self'` blocks third-party script injection.
- `X-Content-Type-Options: nosniff` stops browser from guessing content type.
- `Referrer-Policy: strict-origin-when-cross-origin` keeps full path from leaking to other sites.
- `X-Frame-Options: DENY` blocks clickjacking. Alternative: add `frame-ancestors 'none'` inside Content-Security-Policy.
- `Permissions-Policy: camera=(), microphone=(), geolocation=()` switches off features site not use.

**Omit:**

- `X-XSS-Protection` is deprecated. Modern browsers ignore it. Older versions introduced vulnerabilities.

Combined:

```
Strict-Transport-Security: max-age=31536000; includeSubDomains
Content-Security-Policy: default-src 'self'; frame-ancestors 'none'
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
X-Frame-Options: DENY
Permissions-Policy: camera=(), microphone=(), geolocation=()
```
