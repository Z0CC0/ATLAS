Set these six headers. Omit a seventh.

- **`Strict-Transport-Security: max-age=31536000; includeSubDomains`** forces browsers onto HTTPS. Use 31536000 seconds as the minimum max-age.
- **`Content-Security-Policy: default-src 'self'`** blocks third-party script injection. This header matters most.
- **`X-Content-Type-Options: nosniff`** stops browsers from guessing the content type.
- **`Referrer-Policy: strict-origin-when-cross-origin`** keeps your full URL path from leaking to other sites.
- **`X-Frame-Options: DENY`** protects against clickjacking. Instead, you can add `frame-ancestors 'none'` to your CSP.
- **`Permissions-Policy`** turns off camera, microphone and geolocation. Use it if your site doesn't need them.

Don't send **`X-XSS-Protection`**. It's deprecated. Modern browsers ignore it, and older browsers that used it introduced vulnerabilities.

Complete set:

```
Strict-Transport-Security: max-age=31536000; includeSubDomains
Content-Security-Policy: default-src 'self'; frame-ancestors 'none'
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
X-Frame-Options: DENY
Permissions-Policy: camera=(), microphone=(), geolocation=()
```
