Set these six headers, and leave out X-XSS-Protection.

`Strict-Transport-Security: max-age=31536000; includeSubDomains` makes the browser use HTTPS. The max-age should be at least 31536000 seconds.

`Content-Security-Policy: default-src 'self'` is the header that blocks third-party scripts from being injected.

`X-Content-Type-Options: nosniff` stops the browser from guessing the content type.

`Referrer-Policy: strict-origin-when-cross-origin` keeps the full path from leaking to other sites.

`X-Frame-Options: DENY` protects against clickjacking. You can use `frame-ancestors 'none'` inside the Content-Security-Policy instead.

`Permissions-Policy: camera=(), microphone=(), geolocation=()` turns off the camera, microphone and geolocation. Only set it for features the site doesn't use.

Don't set `X-XSS-Protection`. It's deprecated: modern browsers ignore it, and older browsers that supported it had vulnerabilities because of it.
