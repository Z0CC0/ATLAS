internal knowledge

Wrap the function so each call cancels the pending timer and starts a new one:

```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Usage:

```js
const onResize = debounce(() => console.log('resized'), 200);
window.addEventListener('resize', onResize);
```

Three details make it work:

`clearTimeout(t)` must run before every new `setTimeout`. Without it, timers pile up and `fn` fires more than once.

`let t` must live in the outer closure, not inside the returned function. Otherwise every call gets its own timer, and nothing gets debounced.

`...args` forwards the arguments. Without the spread, `fn` receives nothing.

This version **returns nothing**. If you need `fn`'s return value, you have to wrap it in a Promise.

If you want the opposite, running immediately and then ignoring calls for a period, you need a **throttle**, which is a different function.
