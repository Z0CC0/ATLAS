```js
function debounce(fn, ms) { let t; return (...args) => { clearTimeout(t); t = setTimeout(() => fn(...args), ms); }; }
```

Call `clearTimeout` before every new `setTimeout`. Otherwise timers pile up and the function fires more than once.

Keep `t` in the closure, not inside the returned function. If it lived there, every call would get its own timer and nothing would be debounced.

Pass the arguments on with the spread. Without it, `fn` receives nothing.

This version returns nothing. If you need the return value, use a Promise.

If you want the opposite, where the function runs immediately and then ignores calls for a while, you need a throttle. That's a different function.
