Set these six headers on a static site:

- **`Strict-Transport-Security: max-age=31536000; includeSubDomains`**: forces the browser onto HTTPS. Use a max-age of at least 31536000 seconds.
- **`Content-Security-Policy: default-src 'self'`**: blocks third-party script injection.
- **`X-Content-Type-Options: nosniff`**: stops the browser from guessing the content type.
- **`Referrer-Policy: strict-origin-when-cross-origin`**: stops the full path from leaking to other sites.
- **`X-Frame-Options: DENY`**: protects against clickjacking. You can instead add `frame-ancestors 'none'` to the CSP.
- **`Permissions-Policy: camera=(), microphone=(), geolocation=()`**: turns off these features. Use it only if the site does not need them.

Example:

```
Strict-Transport-Security: max-age=31536000; includeSubDomains
Content-Security-Policy: default-src 'self'; frame-ancestors 'none'
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
X-Frame-Options: DENY
Permissions-Policy: camera=(), microphone=(), geolocation=()
```

Do not set `X-XSS-Protection`. It is deprecated, and modern browsers ignore it. In older browsers it introduced vulnerabilities.
