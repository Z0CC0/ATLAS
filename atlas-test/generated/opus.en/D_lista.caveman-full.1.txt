Static site still needs these seven header decisions:

- **Strict-Transport-Security**: `max-age` at least 31536000 seconds, plus `includeSubDomains`. Forces browser onto HTTPS.
- **Content-Security-Policy**: `default-src 'self'`. Blocks third-party script injection.
- **X-Content-Type-Options**: `nosniff`. Stops browser from guessing content type.
- **Referrer-Policy**: `strict-origin-when-cross-origin`. Full path does not leak to other sites.
- **Clickjacking protection**: `X-Frame-Options: DENY`, or `frame-ancestors 'none'` inside CSP.
- **Permissions-Policy**: switch off camera, microphone and geolocation if site does not use them.
- **X-XSS-Protection**: omit. Header is deprecated. Modern browsers ignore it, and older versions introduced vulnerabilities.

Example set:

```
Strict-Transport-Security: max-age=31536000; includeSubDomains
Content-Security-Policy: default-src 'self'; frame-ancestors 'none'
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
X-Frame-Options: DENY
Permissions-Policy: camera=(), microphone=(), geolocation=()
```

Pick one clickjacking option or send both. Sending both covers browsers that support only one.
