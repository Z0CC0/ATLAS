```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Every call cancels the pending timer and starts a new one. `fn` runs only after `ms` milliseconds with no new calls.

`clearTimeout(t)` has to run before every new `setTimeout`. Without it, timers pile up and `fn` fires more than once.

`t` has to live in the closure, not inside the returned function. Otherwise each call gets its own timer and nothing is debounced.

`...args` has to be spread into `fn`. Without it, `fn` receives no arguments.

This version returns nothing. If you need `fn`'s return value, you need a Promise.

If you want the opposite, running immediately and then ignoring calls for a period, you want a throttle. That's a different function.
