HTTPS is ordinary HTTP sent through a channel encrypted by **TLS**. Your browser and the website still exchange HTTP requests and responses, but before any of that happens they run a TLS handshake to set up a secure connection.

### 1. The client says hello
Your browser (the client) opens the connection and tells the server which TLS versions and ciphers it supports.

### 2. The server answers and shows its certificate
The server picks a cipher and a version from that list and sends back its **certificate**. A certificate binds a domain name, such as `example.com`, to a public key, and a **certificate authority** (CA) signs it.

### 3. The client checks the certificate
The browser verifies the CA's signature by following the chain of signatures up to a **root certificate** it already has. If the chain ends at a root it trusts, it accepts that the public key really belongs to that domain.

### 4. Both sides agree on a session key
The client and server then agree on a shared **session key**. Today this is usually done with an elliptic curve Diffie-Hellman exchange. The session key is **symmetric**, meaning both sides use the same key, because asymmetric (public-key) encryption is too expensive for real traffic. Public-key cryptography is used only to set up the connection, and the cheaper symmetric key protects everything after that.

### 5. Data flows securely
From then on, all traffic is encrypted and authenticated. Anyone sitting between you and the server can't read it, and they can't change it without being detected.

### Speed: TLS 1.2 vs 1.3
The handshake adds delay before any data is sent. TLS 1.2 needs two round trips between client and server, and TLS 1.3 cuts this to one, so connections start faster.

### What HTTPS doesn't tell you
The padlock means you're talking to whoever controls the key for that domain. The certificate says nothing about who runs the site. A scam site can have a perfectly valid certificate for its own domain, so HTTPS means the connection is private and hasn't been tampered with, not that the site can be trusted.
