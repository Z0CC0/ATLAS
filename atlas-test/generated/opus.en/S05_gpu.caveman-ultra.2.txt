RTX 5080 is newer generation. Main gain is frame generation, not raw rasterisation.

- **Architecture:** 5080 uses Blackwell. 4080 uses Ada Lovelace.
- **Memory:** 5080 has GDDR7. 4080 has GDDR6X. Bandwidth rises from about 717 GB/s to about 960 GB/s.
- **Performance:** Biggest jump is frame generation. Rasterisation gain is only about 10–15%.
- **Power:** Rated draw rises from 320 W to 360 W. Power connector stays 16-pin, so same cable works.

If you already own a 4080 and play without frame generation, 10–15% is small upgrade. If you use frame generation heavily, 5080 gives much bigger gain.
