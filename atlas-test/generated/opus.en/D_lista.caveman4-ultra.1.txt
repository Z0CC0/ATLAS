Static site headers:

- **`Strict-Transport-Security: max-age=31536000; includeSubDomains`**: forces the browser onto HTTPS. max-age at least 31536000 seconds.
- **`Content-Security-Policy: default-src 'self'`**: blocks third-party script injection.
- **`X-Content-Type-Options: nosniff`**: stops the browser from guessing the content type.
- **`Referrer-Policy: strict-origin-when-cross-origin`**: full path does not leak to other sites.
- **`X-Frame-Options: DENY`**, or `frame-ancestors 'none'` inside the CSP: protects against clickjacking.
- **`Permissions-Policy: camera=(), microphone=(), geolocation=()`**: turns these off if the site does not use them.

Do not set **`X-XSS-Protection`**. It is deprecated. Modern browsers ignore it, and older versions introduced vulnerabilities.

Combined CSP:
```
Content-Security-Policy: default-src 'self'; frame-ancestors 'none'
```
