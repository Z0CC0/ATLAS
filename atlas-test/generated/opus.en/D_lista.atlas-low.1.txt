For a static site, set these six headers and leave out a seventh:

Strict-Transport-Security: max-age=31536000; includeSubDomains. This forces the browser to use HTTPS. The max-age should be at least 31536000 seconds (one year).

Content-Security-Policy: default-src 'self'. This blocks scripts injected from third-party sources. Add frame-ancestors 'none' to the same header to protect against clickjacking.

X-Frame-Options: DENY. This also protects against clickjacking. It does the same job as frame-ancestors 'none', so you only need one of them.

X-Content-Type-Options: nosniff. This stops the browser from guessing the content type of a file.

Referrer-Policy: strict-origin-when-cross-origin. This keeps the full path of your pages from being sent to other sites.

Permissions-Policy: camera=(), microphone=(), geolocation=(). This turns off those features. Only do this if your site doesn't use them.

**Don't set X-XSS-Protection.** It is deprecated. Modern browsers ignore it, and in older browsers it introduced vulnerabilities.
