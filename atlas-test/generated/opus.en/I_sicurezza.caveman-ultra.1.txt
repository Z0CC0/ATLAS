No. Obfuscation does not protect it. Anything sent to the browser is readable. Someone can open the developer tools or watch the network requests and get the key in seconds.

**What to do instead:**
1. Keep the key on your server.
2. Have the frontend call an endpoint on your own backend. That endpoint then calls the service with the key.
3. Put a rate limit on that endpoint. Without one, anyone can use the endpoint to spend your key for free.

**If the key was already published:**
- Treat it as compromised. Rotate it now. Removing it from the code is not enough.
- Deleting it in a new commit does not remove it from the repository history. Anyone who already has a clone has the key.
