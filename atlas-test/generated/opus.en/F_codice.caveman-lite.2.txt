Here is a debounce function with no library:

```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Usage:

```js
const onResize = debounce(() => console.log('resized'), 200);
window.addEventListener('resize', onResize);
```

Each call cancels the timer that is still waiting and starts a new one. As a result, `fn` runs only once, `ms` milliseconds after the last call.

Three details make it work:

- **Call `clearTimeout(t)` before every new `setTimeout`.** If you skip it, the timers pile up and `fn` runs more than once.
- **Declare `t` in the closure, outside the returned function.** If you declare `t` inside the returned function, every call gets its own timer and nothing is debounced.
- **Forward the arguments with the spread syntax (`...args`).** If you don't, `fn` gets called with no arguments.

Two limits:

- **This version returns nothing.** If you need `fn`'s return value, change the wrapper to return a Promise.
- **It runs `fn` at the end, not at the start.** If you want `fn` to run right away and then ignore calls for a while, you need a throttle, which is a different function.
