Wrap function in closure holding one timer. Each call cancels old timer and starts new one. Function runs only after `ms` pass with no new calls.

```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Usage:

```js
const onResize = debounce(() => console.log('resized'), 200);
window.addEventListener('resize', onResize);
```

What matters:

- **Call `clearTimeout` before every new `setTimeout`.** If you skip it, timers pile up and `fn` fires more than once.
- **Keep `t` in the closure**, outside the returned function. If `t` lives inside the returned function, every call gets its own timer and no debouncing happens.
- **Forward arguments with spread** (`...args`). Without spread, `fn` receives nothing.
- **No return value.** This version returns nothing. If you need the return value from `fn`, return a Promise instead.

Need opposite behavior, where `fn` runs immediately and later calls are ignored for a period? That is throttle, a different function.
