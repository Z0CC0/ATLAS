## 16 bit start

**8086 (1978).** 16 bit. Grows out of 8080, source-level compatible. Backward compatibility shapes every later step.

**80286 (1982).** Adds protected mode. Flaw: no way back to real mode without reboot.

## 32 bit era

**80386 (1985).** 32 bit, paged virtual memory, virtual 8086 mode. Virtual 8086 mode fixes 286 problem: old real-mode code runs inside protected mode.

**486 (1989).** Puts first-level cache and math coprocessor on chip.

## Performance from parallelism

**Pentium (1993).** Superscalar. Two integer pipelines, up to two instructions retired per cycle.

**Pentium Pro (1995).** Big turning point. Adds out-of-order execution. Translates x86 instructions into internal micro-operations. From here x86 is interface only, not real machine underneath.

## Frequency race ends

**Pentium 4 (2000).** Chases clock frequency with very long pipeline. Hits power wall.

**AMD64 (2003).** AMD extends architecture to 64 bit. Intel adopts same instruction set. First time dominant extension does not come from Intel.

**Core 2 (2006).** Direction moves from frequency to core count.

## Vector track

Vector extensions grow across generations: MMX, SSE, AVX, AVX-512.

## Today

Complexity now lives in layers below instruction set: branch prediction, cache hierarchy, speculative execution.

**Spectre and Meltdown (2018).** Show speculative execution carried security cost nobody had priced.

## Pattern

Each generation stays compatible at surface. Real progress moves underneath:
- 386: 32 bit.
- Pentium Pro: micro-operation translation.
- After Pentium 4: multicore.

Spectre and Meltdown show cost of that hidden layer.
