Both `let` and `const` are block scoped. `var` is not.

**`let`**: you can reassign the name.
```js
let count = 1;
count = 2; // OK
```

**`const`**: you cannot reassign the name. The value itself can still change. An object declared with `const` can change internally.
```js
const user = { name: "Ana" };
user.name = "Bo"; // OK, the object changes internally
user = {};        // TypeError, reassignment not allowed
```

Use `const` when the name must always point to the same value. Use `let` when you need to reassign it.
