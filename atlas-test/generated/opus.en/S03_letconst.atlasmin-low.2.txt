`let` lets you reassign a name. `const` doesn't.

`const` only locks the name, not the value. An object declared with `const` can still change internally:

```js
const user = { name: "Ada" };
user.name = "Grace"; // fine: the object changes internally
user = {};           // TypeError: the name can't be reassigned

let count = 1;
count = 2;           // fine: let allows reassignment
```

Both are block scoped, unlike `var`.
