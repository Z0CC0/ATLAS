# x86 evolution, 1978 to today

The story has three phases. First, x86 grows the features of a modern CPU. Then, around 1995, it becomes an interface that sits on top of a different internal machine. Since then, progress has come from more cores, wider vectors and smarter layers underneath, and that last part turned out to have a security cost.

## Phase 1: building the foundations (1978–1989)

**8086 (1978): the starting point**
- 16-bit processor.
- Grew out of the 8080 and was compatible with it at source level, so existing code could be carried over. Compatibility mattered from the very first chip.

**80286 (1982): protected mode, with a catch**
- Introduces protected mode, the basis for an OS that isolates programs from each other.
- The catch: once in protected mode, the only way back to real mode is a reboot.

**80386 (1985): the big jump**
- Moves the architecture to 32 bit.
- Adds paged virtual memory, which modern operating systems are built on.
- Adds virtual 8086 mode, which runs old 16-bit code inside the new environment. This works around the 286's one-way switch.

**486 (1989): integration**
- Moves the first-level cache and the maths coprocessor onto the chip. Both used to be separate parts.

## Phase 2: the hidden machine (1993–2000)

**Pentium (1993): superscalar**
- Two integer pipelines that can retire two instructions per cycle.
- The CPU now does more than one thing at a time instead of one instruction after another.

**Pentium Pro (1995): the turning point**
- Introduces out-of-order execution: instructions run when their inputs are ready, not strictly in program order.
- Translates x86 instructions into internal micro-operations.
- **Why this matters:** from this point on, x86 is an interface, no longer the real machine underneath. Software still speaks x86, but the hardware speaks its own internal language.

**Pentium 4 (2000): the frequency bet**
- Chases clock speed with a very long pipeline.
- Hits the power wall: pushing frequency further costs too much power. This dead end shapes everything that comes after.

## Phase 3: new directions (2003–today)

**AMD64 (2003): the extension comes from outside**
- AMD extends the architecture to 64 bit with AMD64.
- Intel adopts the same instruction set.
- This is the first time the dominant x86 extension does not come from Intel.

**Core 2 (2006): from frequency to cores**
- After the Pentium 4's power wall, the direction changes: add more cores instead of raising the clock.

**Vector extensions: growing across generations**
- MMX → SSE → AVX → AVX-512.
- Each generation lets one instruction work on more data at once.

**Today: complexity lives below the interface**
- The hard engineering sits in the layers you don't see:
  1. Branch prediction
  2. Cache hierarchy
  3. Speculative execution

**Spectre and Meltdown (2018): the bill arrives**
- These attacks showed that speculative execution carried a security cost nobody had priced.
- This follows from the 1995 shift. Once the real machine was hidden under the interface, what it did underneath could leak information in ways the interface never promised to prevent.

## The through-line

| Era | Main idea | Key chips |
|---|---|---|
| 1978–1989 | Add modern features while keeping compatibility | 8086, 286, 386, 486 |
| 1993–2000 | Make the hidden machine faster | Pentium, Pentium Pro, Pentium 4 |
| 2003–today | 64 bit, more cores, wider vectors, deeper hidden layers | AMD64, Core 2, MMX→AVX-512 |
