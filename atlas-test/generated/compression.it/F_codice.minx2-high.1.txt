```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Chiama `clearTimeout` prima di ogni nuovo `setTimeout`. Senza, i timer si accumulano e la funzione parte più volte.

`t` va nella chiusura, **non** dentro la funzione restituita. Lì ogni chiamata avrebbe un proprio timer e il debounce non avverrebbe.

Inoltra gli argomenti con lo spread (`...args`). Senza, la funzione li riceve vuoti.

Questa versione non restituisce niente. Se ti serve il valore di ritorno, usa una Promise.

Se invece vuoi eseguire subito e poi ignorare le chiamate per un certo periodo, ti serve un throttle, che è un'altra funzione.
