Ecco l'implementazione:

```javascript
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

`clearTimeout` va chiamato prima di ogni nuovo `setTimeout`: senza, timer si accumulano e funzione parte piu' volte.

Variabile `t` sta nella chiusura, non dentro funzione restituita: ogni chiamata avrebbe proprio timer, debounce non avverrebbe.

Argomenti vanno inoltrati con spread (`...args`): senza, funzione chiamata li riceve vuoti.

Questa versione non restituisce niente. Serve valore di ritorno, serve Promise.

Caso opposto — eseguire subito poi ignorare per periodo — e' throttle, altra funzione.
