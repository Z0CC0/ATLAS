```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

Chiama sempre `clearTimeout` prima di ogni nuovo `setTimeout`. Se lo salti, i timer si accumulano e la funzione parte più volte.

Tieni `t` nella chiusura, non dentro la funzione restituita. Altrimenti ogni chiamata ha il suo timer e il debounce non avviene.

Inoltra gli argomenti con lo spread (`...args`). Senza, `fn` li riceve vuoti.

Questa versione non restituisce niente. Se ti serve il valore di ritorno, devi usare una Promise.

Se invece vuoi eseguire subito e poi ignorare le chiamate per un periodo, ti serve un throttle, che è un'altra funzione.
