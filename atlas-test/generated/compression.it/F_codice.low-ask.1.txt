```js
function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

clearTimeout va chiamato prima di ogni nuovo setTimeout, altrimenti timer si accumulano e funzione parte più volte.

Variabile `t` sta nella chiusura, non dentro funzione restituita — altrimenti ogni chiamata avrebbe proprio timer, debounce non avverrebbe.

Argomenti inoltrati con spread — altrimenti funzione chiamata riceve argomenti vuoti.

Questa versione non restituisce niente. Se serve valore di ritorno, serve Promise.

Per caso opposto — eseguire subito poi ignorare per periodo — serve throttle, funzione diversa.
